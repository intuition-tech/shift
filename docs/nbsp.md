# Неразрывные пробелы: `tools/nbsp.mjs`

Инструмент ставит неразрывные пробелы в тексте выбранных публикаций. Решения по правилам и режиму запуска — Жени, 30.10.2026.

## Зачем

На старом сайте текст прошёл через типограф: предлоги приклеены к следующему слову, тире — к предыдущему. На новом сайте такие пробелы есть только у страниц, текст которых отрендерен из Pug как есть; в перенабранных и переведённых гайдах их нет. Правило «предлог не висит в конце строки» выполняется инструментом, не руками.

## Когда запускается

Только в двух случаях:

- по прямому запросу — для одной или нескольких названных публикаций;
- при вёрстке новой публикации — один раз, как шаг чеклиста в [content-markup.md](content-markup.md), до коммита.

Никогда по своей инициативе: автоматически (хуки, сборка), по всем страницам разом, между коммитом и публикацией — иначе в прод попадает непросмотренный текст. Запрет — на непрошенный запуск: если агент явно предложил прогон и Женя ответил «давай», это запрос. Так 3 ноября 2026 инструмент прошёл по всем публикациям: текст из Pug оказался типографирован не везде (висячие союзы в MENA, брендбуке и других перенесённых гайдах).

## Запуск

```
node tools/nbsp.mjs <slug> [<slug> …]          # правит src/pages/<slug>.html и заголовки записи в publications.js
node tools/nbsp.mjs src/pages/<slug>.html       # только файл
node tools/nbsp.mjs <slug> --check              # ничего не пишет; печатает строки, где пробелы не стоят; код выхода 1
node tools/nbsp.mjs <slug> --diff               # показывает замены построчно (неразрывный — как ␣), не пишет
```

Без аргументов не делает ничего. Идемпотентен: второй прогон не меняет файл. Уже стоящие неразрывные пробелы не трогает.

## Что обрабатывается

Только текст HTML-страницы и значения `title`/`titleEn` записи публикации в `src/data/publications.js` (заголовки рендерятся в таблицу на главной и переносятся в узких колонках). Не трогаются:

- содержимое `<code>`, `<pre>`, `<script>`, `<style>`, `<svg>`;
- атрибуты (`alt`, `title`, `label` у `ids-nav-item`, `href`);
- фронтматтер, HTML-комментарии;
- теги Nunjucks `{% … %}`, `{{ … }}`, `{# … #}` — текст внутри не трогается, текст между ними обрабатывается как отдельные отрезки;
- `docs/`, остальные поля данных.

Текстовый отрезок заканчивается на любом теге. Короткое слово в конце отрезка перед строчным тегом (`<a>`, `<b>`, `<em>`, `<strong>`, `<span>`, `<mark>`, `<code>`) тоже приклеивается: «в <a>комбо</a>» → «в&nbsp;<a>…». Перед блочным тегом — нет.

Символ — литерал U+00A0, не сущность `&nbsp;`: так его хранит старый сайт и так он лежит в отрендеренных страницах.

## Правила

Общие:

1. **Тире.** Пробел перед «—» неразрывный, после — обычный. Дефисы и «-» вместо тире не заменяются: инструмент не типограф, только пробелы.
2. **Число и следующее слово или единица:** `5 шагов`, `12 px`, `100 %`, `№ 5`, `§ 3`; разряды внутри числа `10 000`.
3. **Инициалы и сокращения:** `И. Афанасьев`, `т. е.`, `т. д.`, `т. п.`, `см.`, `рис.`, `стр.`, `гл.`, `табл.` + следующее слово.

Русский:

4. После слова из 1–2 букв (в, во, с, со, к, ко, о, об, у, и, а, но, да, не, ни, на, по, за, из, от, до, то, же, ли, бы…). Критерий — длина, не словарь. Трёхбуквенные (для, при, без, или, что, как…) не трогаются.
5. Перед частицами же, ли, бы, б, ль: «такого&nbsp;же», «не выглядит&nbsp;ли». Цепочки допускаются: «в&nbsp;этом&nbsp;же комбо».

Английский:

6. После слова из 1–2 букв (a, an, of, in, on, at, to, by, or, as, if, so, is, it, we, be, do, no, up, us…); аббревиатуры из двух заглавных (UK, AI) не считаются. Трёхбуквенные (the, and, for…) не трогаются. Апостроф границей слова не считается: «Here's how» остаётся как есть.

Чего инструмент не делает: не ставит кавычки-ёлочки, не меняет дефис на тире, не убирает двойные пробелы, не переносит висячую пунктуацию.

## Как устроен

Один файл `tools/nbsp.mjs` без зависимостей. Токенайзер по регулярке делит страницу на фронтматтер, комментарии, теги Nunjucks, HTML-теги и текст; для запретных элементов ведётся счётчик вложенности. Правила — список пар «регулярка → замена», применяются к отрезку по кругу, пока текст меняется (цепочки). Для `publications.js` правила применяются к значениям `title`/`titleEn` внутри записи с нужным слагом. Отчёт: файл → сколько пробелов поставлено (или не хватает в `--check`/`--diff`, с номерами строк и фрагментами).
