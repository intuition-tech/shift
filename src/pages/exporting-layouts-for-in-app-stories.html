{% if lang == 'ru' %}Как сохранить сторис из фигмы и правильно назвать файлы с макетами.{% else %}How to save stories in Figma and properly name layout files.{% endif %}

Figma

  1. {% if lang == 'ru' %}Переходим в меню экспорта. Оно находится справа, в нижней части панели инструментов.{% else %}Go to the export menu. It is on the right, at the bottom of the toolbar.{% endif %}
  2. {% if lang == 'ru' %}Выбираем качество 0.75х и формат Jpg.{% else %}Select 0.75x quality and Jpg format.{% endif %}
  3. {% if lang == 'ru' %}Нажимаем кнопку Export и указываем нужный путь файла.{% else %}Click the "Export" button and specify the necessary file path.{% endif %}

{% if lang == 'ru' %}Как называть файлы{% else %}How to name files{% endif %}

{% if lang == 'ru' %}Пользуемся следующей схемой:{% else %}Use the following scheme:{% endif %}

{% if lang == 'ru' %}Макет с обложкой {% else %}Layout with cover{% endif %}

  • RU — Irkutsk — Bear Pizza — Cover
  • {% if lang == 'ru' %}Страна — Город — Название акции / активности — Тип макета (обложка или сторис) — Макеты в сторис.{% else %}Country - City - Name of the campaign/activity - Layout type (cover or stories) - Layouts in stories.{% endif %}

{% if lang == 'ru' %}Макет со сторис{% else %}Layout with stories{% endif %}

  • RU — Irkutsk — Bear Pizza — Story — 1
  • {% if lang == 'ru' %}Страна — Город — Название акции / активности — Тип макета (обложка или сторис) — Порядковый номер сторис.{% else %}Country - City - Name of the action / activity - Layout type (cover or stories) - Ordinal number of stories.{% endif %}

{% if lang == 'ru' %}Обязательно проверяем порядковые номера макетов, чтобы не перепутать последовательность и загрузить сторис в приложение в нужном порядке.{% else %}Make sure to check the ordinal numbers of layouts, so that you don't mix up the sequence and upload stories to the application in the right order.{% endif %}
