{% if lang == 'ru' %}Шаблон папки проекта{% else %}Project folder template{% endif %}

{% if lang == 'ru' %}Чтобы сэкономить время и не создавать папки вручную, используйте шаблон папки проекта. В нём уже есть папки для всех носителей. Надо только скачать его и удалить лишние.{% else %}To save some time and not create folders manually, use project folder template. It already contains folders for all media. All you have to do is download it and delete the extra ones.{% endif %}

{% if lang == 'ru' %}Вот как пользоваться шаблоном.{% else %}Here's how to use the template.{% endif %}

  1. {% if lang == 'ru' %}Скачайте шаблон и удалите папки с носителями, которые не используются в вашем проекте.{% else %}Download your template and delete the media folders that are not used in the project.{% endif %}
  2. {% if lang == 'ru' %}В папке [Sketch] работайте над скетчем, добавляйте туда любой контент. Возможно, ваши наработки пригодятся в других проектах.{% else %}Use the [Sketch] folder to work on your sketch. You can put anything you want into it. Perhaps your developments can be of some use for other projects.{% endif %}
  3. {% if lang == 'ru' %}В папку [Master Layout] положите мастер-макет и используйте его при тиражировании.{% else %}Put the master layout into the [Master Layout] folder and use it for replication.{% endif %}
  4. {% if lang == 'ru' %}В папку [Links] добавляйте все объекты, которые линкуются к мастер-макету и в дальнейшем ко всем Process-файлам при тираже.{% else %}Add all the objects, which are linked to the master-layout and, further to all the Process-files at replication, to the [Links] folder.{% endif %}
  5. {% if lang == 'ru' %}Внутри папок с носителями есть папки [Process]. В них лежат шаблоны носителей с заданными размерами, припусками на обрез, футерами и направляющими. Используйте их для тиражирования.{% else %}There are [Process] folders inside the media folders. They contain media templates with specified sizes, trim allowances, liners and guides. Use them for replication.{% endif %}
  6. {% if lang == 'ru' %}Заполненную папку загрузите на гугл-диск.{% else %}Upload the filled folder to the Google Drive.{% endif %}

{% if lang == 'ru' %}Вот примеры реальных проектов. Посмотрите их, чтобы лучше понять как работают папки.{% else %}Here are the examples of real projects. Take a look at them to see how the folders work.{% endif %}

{% if lang == 'ru' %}Названия слоёв{% else %}Layouts names{% endif %}

{% if lang == 'ru' %}Мы оставляем названия слоёв в шаблонах без изменений. Когда тиражирование будет автоматизировано, это поможет скриптам и роботам понимать, что где лежит, и делать за нас рутинную работу.{% else %}We leave the names of the layers in the templates unchanged. When replication becomes automatized, it will help scripts and robots understand what is where and do our routine tasks.{% endif %}

{% if lang == 'ru' %}Название слоя зависит от того, что в нём находится.{% else %}The name of the layer depends on what's in it.{% endif %}

{% if lang == 'ru' %}Guidelines — сетки и направляющие.{% else %}Guidelines — grids and guides.{% endif %}

{% if lang == 'ru' %}Preview — элементы интерфейса, окружающего макет. Отличаются для разных носителей.{% else %}Preview — interface elements surrounding the layout. They are different for each type of media.{% endif %}

{% if lang == 'ru' %}Text — текст, плашки, ценники, леттеринг.{% else %}Text — text, bars, price tags, lettering.{% endif %}

{% if lang == 'ru' %}Footer — футеры с логотипами, навигацией.{% else %}Footer — footers with logos and navigation.{% endif %}

{% if lang == 'ru' %}Background — для фона, фотографий продуктов, графики и всяких графических элементов, которые не текст.{% else %}Background — background, product photos, graphic elements that are not a text.{% endif %}
