{% if lang == 'ru' %}Реализация проекта{% else %}Project implementation{% endif %}

{% if lang == 'ru' %}Как собрать команду, продукт и логистику так, чтобы коллаборация доехала до пиццерий и не встала на старте.{% else %}How to assemble the team, product and logistics so the collaboration reaches pizzerias and does not stall at launch.{% endif %}

{% if lang == 'ru' %}Когда партнёр выбран и рамки проекта ясны, начинается реализация. Команды собирают продукт, упаковку и мерч, запускают продакшен, выстраивают логистику и продвижение и готовят сеть к старту.{% else %}Once the partner is chosen and the project frame is clear, implementation begins. Teams assemble the product, packaging and merch, start production, set up logistics and promotion, and prepare the network for launch. At this stage the idea becomes a concrete offer that must reach pizzerias and sell without surprises.{% endif %}

{% if lang == 'ru' %}Такой запуск всегда кросскомандный и идёт несколько месяцев. Им управляет менеджер проекта: он держит темп, зоны ответственности и единый контекст — кто за что отвечает, где мы сейчас и к чему идём. От этого зависит, соберутся ли блоки вовремя и не разъедутся ли команды по разным версиям плана.{% else %}Such a launch is always cross-team and runs for several months. A project manager runs it: they hold the pace, areas of responsibility and a shared context — who owns what, where we are now and what we are heading towards. That determines whether the blocks come together on time and whether teams stay on the same version of the plan.{% endif %}

{% if lang == 'ru' %}В работе менеджера опираемся на несколько правил:{% else %}In the manager’s work we rely on several rules.{% endif %}

  • {% if lang == 'ru' %}Ясная рабочая группа с прозрачными зонами ответственности.{% else %}A clear working group with transparent areas of responsibility.{% endif %}
  • {% if lang == 'ru' %}Единый контекст у всей команды: в какой точке мы сейчас и к чему идём.{% else %}A shared context for the whole team: where we are now and what we are heading towards.{% endif %}
  • {% if lang == 'ru' %}Адекватный темп: сроки должны оставлять время подумать, как сделать лучше, чем в прошлый раз, при этом проект динамичный и требует фокуса от рабочей группы.{% else %}An adequate pace. Timelines should leave room to think about how to do better than last time. At the same time the project is dynamic and needs focus from the working group.{% endif %}

{% if lang == 'ru' %}Создаём канал проекта и описываем командам сетап{% else %}Create the project channel and share the setup with teams{% endif %}

{% if lang == 'ru' %}На этапе подготовки мы уже определили, что будет в коллаборации: партнёр, рамки проекта, тайминг и прогноз. Реализация начинается с того, что менеджер собирает эту информацию в одно место и создаёт канал проекта — чтобы все внутренние команды подключились из одной логики.{% else %}At preparation we have already defined what the collaboration will be: the partner, the project frame, timing and forecast. Implementation starts with the manager gathering that information in one place and creating a project channel — so all internal teams join from the same logic.{% endif %}

{% if lang == 'ru' %}Менеджер создаёт канал в Time. Если проект под строгим NDA, канал закрытый. Если нет — открытый, и туда приглашают все команды.{% else %}The manager creates a channel in Time. If the project is under a strict NDA, the channel is closed. If not — it is open, and all teams are invited.{% endif %}

{% if lang == 'ru' %}Time — корпоративный мессенджер.{% else %}Time is the corporate messenger.{% endif %}

{% if lang == 'ru' %}Над коллаборацией работают несколько команд: аналитика, маркетинг, креатив, продукт, логистика, медиа, операционка. Просим лидеров выделить конкретных людей на проект: кто из стратегов, какой арт-директор.{% else %}Several teams work on a collaboration: analytics, marketing, creative, product, logistics, media, operations. We ask leads to assign specific people to the project: which strategist, which art director.{% endif %}

{% if lang == 'ru' %}В канале пишем вводное сообщение: даты запуска, следующие шаги, дата вводной встречи. Тегаем ответственных, прикладываем ссылку на тайминги проекта и на презентацию запуска. Так все видят и сроки, и как будет выглядеть запуск. Сообщение закрепляется. Вся коммуникация по проекту идёт через этот канал — единое окно для всех команд.{% else %}In the channel we post an intro message: launch dates, next steps, kickoff meeting date. We tag the people in charge and attach links to project timings and the launch presentation. That way everyone can see both the schedule and what the launch will look like. The message is pinned. All project communication goes through this channel — a single window for every team.{% endif %}

{% if lang == 'ru' %}По крупным темам создаём отдельные треды: запуски в других странах, дегустации, конкретный продукт. В крупном проекте в одном канале легко набирается около 50 тредов. После старта появляются новые треды под срочные вопросы.{% else %}For major topics we create separate threads: launches in other countries, tastings, a specific product. In a large project one channel easily gathers around 50 threads. After launch, new threads appear for urgent issues.{% endif %}

{% if lang == 'ru' %}Кик-офф{% else %}Kick-off{% endif %}

{% if lang == 'ru' %}Когда канал заведён и ответственные люди выделены, собираем кик-офф — общую встречу всех команд с презентацией запуска. На ней все получают одну и ту же картину: для какой аудитории запускаемся, какой продукт возможен, какие цели у проекта, что планируем и в какие сроки. Так команда выходит в разработку стратегии из единого контекста.{% else %}Once the channel is set up and the people responsible are assigned, we hold a kick-off — a meeting of all teams with the launch presentation. Everyone gets the same picture: which audience we are launching for, what product is possible, what the project goals are, what we are planning and on what timeline. That way the team moves into strategy work from a shared context.{% endif %}

{% if lang == 'ru' %}Готовим бриф{% else %}Preparing the brief{% endif %}

{% if lang == 'ru' %}Когда команды ознакомились с сетапом коллаборации на кик-оффе, команда проекта собирает вводные и брифует стратегов. Параллельно подключаем арт-дирекшн и лидера маркетинга: в арт-дирекшне обычно работают арт-директор и копирайтер, а у нас креативщики и копирайтеры часто совмещают эти роли.{% else %}Once the teams have taken in the collaboration setup at the kick-off, the project team gathers the inputs and briefs the strategists. In parallel we bring in art direction and the marketing lead: art direction usually means an art director and a copywriter, and here creatives and copywriters often combine both roles.{% endif %}

{% if lang == 'ru' %}Стратеги закрывают свою часть: выделяют RTB — критерии, за счёт которых аудитория сможет купить продукт, — и прорабатывают позиционирование коллаборации и самого продукта: о каких смыслах говорить, что откликнется у аудитории, с каким лозунгом выйти.{% else %}Strategists close their part: they define RTB — the reasons that will make the audience buy the product — and work through the positioning of the collaboration and of the product itself: which meanings to communicate, what will resonate with the audience, what slogan to use.{% endif %}

{% if lang == 'ru' %}RTB (англ. reason to believe) — причина верить: то, почему аудитория должна купить продукт{% else %}RTB (reason to believe) — why the audience should buy the product{% endif %}

{% if lang == 'ru' %}Менеджер склеивает вводные по проекту и работу стратегов в один большой бриф — им потом брифуют команду креатива на Big Idea.{% else %}The manager stitches the project inputs and the strategists’ work into one big brief — that is what we then use to brief creative on the Big Idea.{% endif %}

{% if lang == 'ru' %}Весь бриф коллаборации Winx{% else %}Full brief for the Winx collaboration{% endif %}

{% if lang == 'ru' %}Брифуем креативную команду на разработку Big Idea{% else %}Briefing the creative team to develop the Big Idea{% endif %}

{% if lang == 'ru' %}Когда большой бриф собран, брифуем креативную команду на разработку Big Idea. Им дают контекст партнёра и задачи проекта — не готовую большую идею коллаборации, по которой осталось нарисовать макеты. Креатив упаковывает это в одну большую идею: о чём запуск, как он звучит и выглядит.{% else %}Once the big brief is ready, we brief the creative team to develop the Big Idea. They get the partner context and the project tasks — not a ready-made collaboration idea they only need to draw layouts from. Creative packs that into one big idea: what the launch is about, how it sounds and how it looks.{% endif %}

{% if lang == 'ru' %}Результат этапа — утверждённая идея, которую потом воплощают в упаковке, мерче, макетах и других носителях. В идеале продукт идёт следом за идеей. На практике потоки часто идут параллельно, и идеи по продуктам нередко появляются раньше концепции — например, так было в коллаборации Winx: идея продукта появилась раньше брифинга креативной команды.{% else %}The outcome of this stage is an approved idea, which is then embodied in packaging, merch, layouts and other carriers. Ideally the product follows the idea. In practice the streams often run in parallel, and product ideas often appear before the concept — for example, in the Winx collaboration the product idea came before the creative team briefing.{% endif %}

{% if lang == 'ru' %}Разрабатываем продукт{% else %}Developing the product{% endif %}

{% if lang == 'ru' %}Когда большая идея определена — или пока креатив ещё над ней работает — переходим к продукту. Над ним работают команды меню, продуктового маркетинга и R&D (лаборатория): менеджер передаёт вводные по направлению франшизы, вкусам и странам, команды собирают варианты рецептуры и форм-фактора.{% else %}Once the big idea is set — or while creative is still working on it — we move to the product. The menu, product marketing and R&D (lab) teams work on it: the manager passes on inputs on franchise direction, flavours and countries, and the teams assemble recipe and form-factor options.{% endif %}

{% if lang == 'ru' %}Цель этапа — разработать продукт, который отвечает коллаборации и будет продаваться в пиццериях. У нас есть ограничения: загруженность сети, нехватка сотрудников в пиццериях, другие новинки в меню, которые тоже нужно учитывать. Коллаборация должна вписаться в общую картину, а не усложнить работу на местах.{% else %}The goal of this stage is to develop a product that fits the collaboration and will sell in pizzerias. We have constraints: network workload, staff shortages in pizzerias, other menu launches that also need to be accounted for. The collaboration has to fit the overall picture, not make work harder on the ground.{% endif %}

{% if lang == 'ru' %}На брифинги обязательно зовём команду операционки — она сразу подсвечивает риски. Например, «такой напиток не возится в доставку — нет крышек» или «это блюдо слишком сложное для кухни». Всё, что придумываем, обсуждаем с ней: важно понимать, как продукт будет готовиться, храниться и доставляться, а не только как он будет выглядеть в рекламных макетах и на витрине.{% else %}We always bring the operations team to briefings — they flag risks right away. For example, “this kind of drink won't work for delivery — no lids” or “this dish is too complex for the kitchen”. Everything we come up with is discussed with them: it matters how the product will be prepared, stored and delivered, not only how it will look in advertising layouts and on the counter.{% endif %}

{% if lang == 'ru' %}Вот несколько обязательных правил, которым мы следуем при разработке продукта.{% else %}Here are several mandatory rules we follow when developing the product.{% endif %}

{% if lang == 'ru' %}Собираем из того, что уже есть{% else %}Build from what is already there{% endif %}

{% if lang == 'ru' %}Стараемся собирать продукт из того, что уже есть в пиццериях: взять текущие ингредиенты, добавить один новый соус — и уже получился новый продукт, который легче запустить.{% else %}We try to build the product from what pizzerias already have: take current ingredients, add one new sauce — and you already have a new product that is easier to launch.{% endif %}

{% if lang == 'ru' %}Ограничиваем число уникальных составляющих{% else %}Limit the number of unique components{% endif %}

{% if lang == 'ru' %}Есть правило: не больше трёх уникальных составляющих. Сюда входит не только сам продукт, но и упаковка, и мерч. Каждая составляющая — это то, что курьер должен положить в сумку, не забыть, правильно пробить и положить в нужную коробку.{% else %}There is a rule: no more than three unique components. This includes not only the product itself, but packaging and merch too. Each component is something the courier must put in the bag, not forget, ring up correctly and put in the right box.{% endif %}

{% if lang == 'ru' %}Учитываем халяль-регионы{% else %}Account for halal regions{% endif %}

{% if lang == 'ru' %}Есть халяль-регионы: если ингредиент нельзя заменить на халяльный, для этих пиццерий заводим похожий продукт с другим составом — например, куриная ветчина халяль вместо курицы без сертификата.{% else %}There are halal regions: if an ingredient can't be replaced with a halal one, we launch a similar product with a different composition for those pizzerias — for example, halal chicken ham instead of chicken without certification.{% endif %}

{% if lang == 'ru' %}Халяльное мясо — это мясо здорового животного, забитого по исламским правилам с произнесением имени Бога и с полным спуском крови{% else %}Halal meat is meat from a healthy animal, slaughtered according to Islamic rules with the name of God spoken and with the blood fully drained{% endif %}

{% if lang == 'ru' %}Согласовываем продукт с юристами{% else %}Align with legal{% endif %}

{% if lang == 'ru' %}Юристы подсказывают правила акций и отдельно готовят юридические правила для клиентов: механику акции и ограничения на покупку — например, что нельзя купить два продукта в одни руки. Если у акции есть ограничения, правила должны быть доступны клиентам заранее.{% else %}Lawyers advise on promotion rules and separately prepare legal rules for customers: the promotion mechanic and purchase limits — for example, that you can't buy two products in one order. If the promotion has limits, the rules should be available to customers in advance.{% endif %}

{% if lang == 'ru' %}Когда идея, состав и подход к продвижению согласованы, переходим к следующему этапу.{% else %}When the idea, composition and promotion approach are aligned, we move to the next stage.{% endif %}

{% if lang == 'ru' %}Разрабатываем упаковку{% else %}Developing packaging{% endif %}

{% if lang == 'ru' %}Когда идея продукта ясна, идём в упаковку. Цель этапа — уникальная упаковка и комплексное предложение, которое выделяется на полке и в доставке.{% else %}Once the product idea is clear, we move into packaging. The goal of this stage is unique packaging and a comprehensive offer that stands out on the shelf and in delivery.{% endif %}

{% if lang == 'ru' %}Если мы уже в начале знаем, что хотим делать сложную упаковку, предупреждаем команду упаковки об этом ещё на кик-офф-встрече. Говорим, что будем делать уникальную упаковку, а конкретные решения принесём позже.{% else %}If we already know at the start that we want complex packaging, we warn the packaging team about it as early as the kick-off meeting. We say we will make unique packaging and bring the concrete decisions later.{% endif %}

{% if lang == 'ru' %}Выбираем подход{% else %}Choose the approach{% endif %}

{% if lang == 'ru' %}Подход зависит от сроков и креатива. Есть два основных сценария.{% else %}The approach depends on timelines and creative. There are two main scenarios.{% endif %}

  • {% if lang == 'ru' %}Только дизайн. Ориентир — примерно 3–6 месяцев. На срок влияют тип упаковки и регионы запуска: обновить дизайн стаканов проще и быстрее, чем дизайн коробок для пиццы. Если новый дизайн едет на всю Россию, включая Дальний Восток, логистика растягивается. В коллаборации отдельно закладываем время на согласование с партнёром.{% else %}Design only. The guide is roughly 3–6 months. Timelines depend on the packaging type and launch regions: updating cup design is simpler and faster than pizza box design. If the new design goes across all of Russia, including the Far East, logistics stretches out. In a collaboration we separately build in time for partner approval.{% endif %}
  • {% if lang == 'ru' %}Форма и дизайн. Ориентир — около 4–8 месяцев: сюда добавляется разработка конструкции. На срок влияют сложность идеи и то, есть ли у поставщика похожий вариант на складе — тогда разработка идёт быстрее. На Winx, например, меняли форму упаковки, чтобы сильнее выделить предложение.{% else %}Form and design. The guide is about 4–8 months: construction development is added here. Timelines depend on how complex the idea is and whether the supplier already has a similar option in stock — then development goes faster. On Winx, for example, we changed the packaging form to make the offer stand out more.{% endif %}

{% if lang == 'ru' %}Брифуем команду{% else %}Brief the team{% endif %}

{% if lang == 'ru' %}Брифуем команду упаковки. Ответственный за задачу собирает бриф, техническая сторона дополняет требования. Вместе оцениваем задачу, сроки и приоритет, затем брифуем подрядчика: смогут ли сделать и есть ли готовые варианты под наше техническое задание.{% else %}We brief the packaging team. The person responsible for the task puts the brief together, and the technical side adds requirements. Together we assess the task, timelines and priority, then brief the contractor: can they do it and are there ready options for our technical brief.{% endif %}

{% if lang == 'ru' %}Процесс разработки упаковки в Holst{% else %}Packaging development process in Holst{% endif %}

{% if lang == 'ru' %}Разрабатываем конструкцию и дизайн{% else %}Develop construction and design{% endif %}

{% if lang == 'ru' %}Параллельно идут конструкция и дизайн: получаем первые макеты и образцы. Дизайн опирается на брендбук партнёра — тот, что запрашивали ещё на этапе подготовки, — на креативную концепцию и на ограничения производства. Например, на упаковке пиццы можно использовать только четыре цвета.{% else %}Construction and design run in parallel: we get the first layouts and samples. Design builds on the partner’s brandbook — the one we requested during preparation — on the creative concept and on production constraints. For example, pizza packaging can use only four colours.{% endif %}

{% if lang == 'ru' %}Проверяем образцы и ищем поставщиков{% else %}Check samples and find suppliers{% endif %}

{% if lang == 'ru' %}Образцы проверяем на безопасность, на то, как ведёт себя продукт в упаковке, и на удобство сборки в пиццерии. Если образец не сходится с техническим заданием — дорабатываем. Когда вариант финальный, ищем поставщиков, запрашиваем образцы, отбираем, с кем идём дальше, и смотрим стоимость, возможности и сроки.{% else %}We check samples for safety, how the product behaves in the packaging and how easy it is to assemble in the pizzeria. If the sample does not match the technical brief — we iterate. When the option is final, we look for suppliers, request samples, choose who we go with and check cost, capabilities and timelines.{% endif %}

{% if lang == 'ru' %}Согласовываем{% else %}Get approval{% endif %}

{% if lang == 'ru' %}Сначала согласовываем макет внутри, потом отправляем лицензиару. Время на согласование с партнёром закладываем в тайминг отдельно. Финальное решение принимает лидер маркетинга.{% else %}First we approve the layout internally, then we send it to the licensor. Time for partner approval goes into the timeline separately. The marketing lead makes the final decision.{% endif %}

{% if lang == 'ru' %}Упаковка и мерч часто идут параллельно — когда конструкция и дизайн упаковки в работе, уже можно переходить к мерчу.{% else %}Packaging and merch often run in parallel — once packaging construction and design are underway, we can already move to merch.{% endif %}

{% if lang == 'ru' %}Разрабатываем мерч{% else %}Developing merch{% endif %}

{% if lang == 'ru' %}Параллельно с упаковкой — или следом за ней — разрабатываем мерч. Цель этапа — выбрать форм-фактор и довести дизайн до согласования с лицензиаром.{% else %}In parallel with packaging — or right after it — we develop the merch. The goal of this stage is to choose the form factor and take the design through to licensor approval.{% endif %}

{% if lang == 'ru' %}Если мерч производит агентство, оно присылает варианты в рамках креативной концепции. По бюджету и срокам выбираем форму. Всё согласовывают креативная команда и менеджер. Параллельно прорабатываем дизайн и отправляем лицензиару на согласование.{% else %}If an agency produces the merch, it sends options within the creative concept. We choose the form by budget and timeline. The creative team and the manager approve everything. In parallel we work through the design and send it to the licensor for approval.{% endif %}

{% if lang == 'ru' %}Если есть механика выдачи мерча за покупку, все коммуникации про подарок должны содержать юридический лигал.{% else %}Legal note. If there's a mechanic for giving merch with a purchase, all communications about the gift must include legal copy.{% endif %}
