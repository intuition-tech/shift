{% if lang == 'ru' %}Технические рекомендации по организации съемок{% else %}How to prepare for a photo shoot: technical recommendations{% endif %}

{% if lang == 'ru' %}Чтобы получить естественные, но при этом эстетичные снимки, мы заранее выбираем локацию, готовим освещение, приглашаем героев. В этой гайде о том, как мы готовимся к съемке и выстраиваем кадр в процессе.{% else %}To get natural yet aesthetically pleasing shots, we choose the location, prepare the lighting, and invite the characters beforehand. This guide is about how we prepare for the shoot and set up the frame in the process.{% endif %}

{% if lang == 'ru' %}Локация, фон и детали{% else %}Location, background and details{% endif %}

  1. {% if lang == 'ru' %}Избавляемся от визуального шума. Перед съемкой расчищаем кассовую зону, убираем лишние маркетинговые носители или вешалки с вещами. При этом сохраняем контекст: показываем, где находимся.{% else %}Get rid of visual noise. Before shooting, clear the checkout area, remove unnecessary marketing media or hangers with clothes. At the same time, hold on to the context; demonstrate where we are.{% endif %}
  2. {% if lang == 'ru' %}Используем эффект размытия. Так кадр получается более эстетичным и чистым. Следим за динамикой и естественностью поведения героев, чтобы снимок не превратился в стоковую картинку.{% else %}Use the blur effect. This makes the frame clearer and more pleasing aesthetically. We follow the dynamics and natural behavior of the characters, so that the shot does not turn into a stock image.{% endif %}
  3. {% if lang == 'ru' %}Управляем содержанием кадра. Двигаем вешалки, мебель, светильники, стулья и столы.{% else %}Be in control of the content within the frame. Move hangers, furniture, lamps, chairs and tables around.{% endif %}
  4. {% if lang == 'ru' %}Отсматриваем кадры в процессе. В съемках участвует человек, который в моменте следит за чистотой кадра: замечает, когда нужно поднять светильник, очистить стол на заднем плане, сдвинуть гору мопедов у фасада.{% else %}Review the shots in process. The shooting involves a person who makes sure the frame is clear while the shoot is in progress, keeping an eye on when to raise a lamp, clean off a table in the background, and move a bunch of scooters at the front.{% endif %}

{% if lang == 'ru' %}Люди в кадре{% else %}People in the frame{% endif %}

{% if lang == 'ru' %}Перед съемками мы просим героев подписать согласие на использование изображений, где фиксируем условия передачи прав на фото бренду.{% else %}Before shooting, we ask the models to sign a consent agreement to use the images, where we secure the terms of transferring the rights to the photo to the brand.{% endif %}

{% if lang == 'ru' %}Работа с профессиональными актерами{% else %}Working with professional actors{% endif %}

{% if lang == 'ru' %}Это самый простой, но дорогой вариант. Мы объясняем актерам, что нам важна естественность; просим представить, будто они сидят в пиццерии с друзьями, а фотографа рядом нет. Это помогает убрать театральность и получить естественные кадры.{% else %}This is the simplest but pricey option. We make sure the actors understand that authenticity is important to us; we ask them to imagine that they are sitting in a pizzeria with friends, and there is no photographer around. This helps to remove the theatricality and get natural shots.{% endif %}

{% if lang == 'ru' %}Работа с друзьями или клиентами{% else %}Working with friends or clients{% endif %}

{% if lang == 'ru' %}Изучаем соцсети людей, которых собираемся пригласить на съемку. Смотрим, насколько разнообразные и динамичные эмоции они показывают, как улыбаются и ведут себя на камеру. Приглашаем самых харизматичных героев.{% else %}We examine the social networks of the people we are going to invite to the shoot. We see if the emotions they display are dynamic and diverse, the way the models smile and behave on camera. We invite the most charismatic characters.{% endif %}

{% if lang == 'ru' %}Эмоции{% else %}Emotions{% endif %}

  1. {% if lang == 'ru' %}Вдохновляемся реальными людьми. Обращаем внимание, как ведут себя люди в наших пиццериях: одиночки, пары, компании, коллеги. За основу берем их поведение и эмоции, на съемках добавляем немного динамики и дружелюбности.{% else %}Find inspiration in real people’s actions. We pay attention to how people in our pizzerias behave: singles, couples, companies, colleagues. We take their behavior and emotions as a basis, and induce some dynamic and friendliness on the set.{% endif %}
  2. {% if lang == 'ru' %}Подчеркиваем эмоции. В реальности люди, которые приходят пообедать в одиночестве, мало улыбаются и часто смотрят в телефон. Чтобы получить более выразительный кадр, просим героев показать эмоции.{% else %}Highlight emotions. In reality, people who come to dine alone, smile very little and check their phones often. To get a more expressive shot, ask the characters to show emotions.{% endif %}
  3. {% if lang == 'ru' %}Сохраняем умеренность. Слишком эмоциональный кадр будет выглядеть сюрреалистично и неестественно. Чтобы передать актерам нужное настроение, используем фразу: «Вы спокойны, но в отличном расположении духа. Это не радость от рождения ребенка, а просто очередной отличный день».{% else %}Maintain moderation. An overly emotional shot will look surreal and unnatural. To convey the right mood to the actors, use the phrase: "You are laid-back, but in a great mood. It's not the joy of having a baby, it's just another great day."{% endif %}
  4. {% if lang == 'ru' %}Учитываем контекст. Если люди отмечают день рождения в пиццерии, показываем радость и яркие эмоции. С помощью деталей рассказываем зрителю, что перед ним праздник: используем в кадре колпаки, свечи, торт, подарки.{% else %}Consider the context. If people celebrate a birthday in a pizzeria, show joy and bright emotions. With the help of details, we tell the viewer that it's a celebration: we use such props as birthday hats, candles, a cake, and gifts.{% endif %}

{% if lang == 'ru' %}Позы и движения{% else %}Postures and motions{% endif %}

  1. {% if lang == 'ru' %}Даем героям свободу. Не предлагаем актерам занять жесткую позу, а обозначаем границы в пространстве, в рамках которых они могут двигаться. Это помогает сохранить естественность.{% else %}Give the characters freedom. We don't ask our actors to take a rigid posture, but mark the boundaries in the space within which they can move. This helps to keep things natural.{% endif %}
  2. {% if lang == 'ru' %}Корректируем детали. Соблюдаем баланс между естественностью и эстетикой. Если не удается найти нужный ракурс, направляем героя. Например, когда нужно снять экран приложения, а герой неудачно держит смартфон. В этом случае можем слегка повернуть руку или фигуру.{% else %}Correct the details. We keep a balance between naturalness and aesthetics. If you can't find the right angle, guide the character. For example, when you need to take a shot of an application screen, and the model is holding the smartphone inaccurately. In this case, we can slightly rotate the hand or figure.{% endif %}

{% if lang == 'ru' %}Свет{% else %}Light{% endif %}

  1. {% if lang == 'ru' %}Учитываем погодные условия и ограничения пространства. Свет сильно влияет на настроение снимка, поэтому мы всегда заранее продумываем, какие источники света будут в помещении и какие дополнительные инструменты нам понадобятся.{% else %}Take the weather conditions and space limitations into consideration. Light has a big impact on the mood of a shot, so we always think ahead of time about what light sources will be available in the room and what additional equipment we may need.{% endif %}
  2. {% if lang == 'ru' %}Стараемся снимать при естественном свете. Дожидаемся солнца, если есть возможность. Используем искусственные источники и отражатели для корректировки деталей.{% else %}We try to shoot under the natural light. We wait for the sun, if possible. We use artificial sources and reflectors to correct the details.{% endif %}

{% if lang == 'ru' %}Ракурс и стиль съемки{% else %}Angle and shooting style{% endif %}

{% if lang == 'ru' %}Репортажная{% else %}Reportage{% endif %}

{% if lang == 'ru' %}Снимаем естественное течение событий, не пытаясь повлиять на них. В репортажной съемке фотограф не всегда имеет полный контроль над фоном, освещением или композицией. В итоге брендовые элементы или продукты могут быть видны недостаточно.{% else %}Capture the normal flow of events without trying to impact them. In reportage photography, the photographer doesn't always have full control over the background, lighting or composition. As a result, branded elements or products may not be seen enough.{% endif %}

{% if lang == 'ru' %}Стилизованный репортаж{% else %}Reportage-like shooting{% endif %}

{% if lang == 'ru' %}Представляем ситуацию: в пиццерию с идеальным светом пришел хороший уличный репортажник; гости его не заметили и вели себя максимально естественно; фотограф фиксировал моменты в режиме наблюдателя. Такого эффекта мы добиваемся во время съемок.{% else %}Let's imagine a situation: a good street reporter comes to a pizzeria with perfect light; the guests don't notice him and behave as naturally as possible; the photographer captures the moments as an external observer. This is the effect we aim at during shooting.{% endif %}

{% if lang == 'ru' %}Какие делаем стилизованный репортаж:{% else %}How we achieve the desired effect:{% endif %}

  • {% if lang == 'ru' %}используем объектив с большим фокусным расстоянием;{% else %}we use lenses with a long focal length;{% endif %}
  • {% if lang == 'ru' %}создаем несколько планов на снимке и включаем в кадр объекты, которые как бы залезают на передний план;{% else %}create several perspectives in the picture and include objects, which seem to “crawl” into the foreground, into the frame;{% endif %}
  • {% if lang == 'ru' %}снимаем издалека, чтобы создать эффект «подглядывания».{% else %}shoot from a distance to create a "peek-a-boo" effect.{% endif %}

{% if lang == 'ru' %}Кадрирование{% else %}Cropping{% endif %}

{% if lang == 'ru' %}Кадрируем изображения, чтобы сделать акцент на основном объекте, улучшить композицию, удалить ненужные элементы или крупнее показать продукт.{% else %}Crop images to highlight the main object, to improve composition, to remove unnecessary elements or to zoom in the product.{% endif %}

{% if lang == 'ru' %}Инструменты для съемки: смартфон или фотоаппарат{% else %}Tools for shooting: smartphone or camera{% endif %}

{% if lang == 'ru' %}Выбираем инструмент, отталкиваясь от формата и возможностей локации. Следим, чтобы резкости и качества инструмента было достаточно.{% else %}Choose a tool based on the format and capabilities of the location. Make sure that the sharpness and quality of the tool are sufficient.{% endif %}
