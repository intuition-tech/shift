{% if lang == 'ru' %}Постер Pizza slice{% else %}Pizza slice poster{% endif %}

{% if lang == 'ru' %}Адаптируем под локальный рынок и готовим к печати интерьерный постер Pizza slice. В гайде — видеоинструкция и ее расшифровка с иллюстрациями.{% else %}We adapt to the local market and prepare for printing an interior Pizza slice poster. The guide contains step-by-step instructions with illustrations.{% endif %}

{% if lang == 'ru' %}Рассмотрим, как вставить текст на языке страны, выбрать цвет фона и правильно сохранить постер для передачи в типографию.{% else %}Let's take a look at how to insert text written in your local language, choose a background colour and correctly save the poster before taking it to the printing.{% endif %}

{% if lang == 'ru' %}Прежде чем приступить к редактированию макета, выполните несколько предварительных шагов:{% else %}Before you start editing your layout, follow a few preliminary steps:{% endif %}

  1. {% if lang == 'ru' %}Установите пресет для сохранения PDF.{% else %}Install a preset for saving PDF.{% endif %}
  2. {% if lang == 'ru' %}Уточните порядковый номер пиццерии.{% else %}Clarify the pizzeria’s serial number.{% endif %}
  3. {% if lang == 'ru' %}Уточните, какой цвет фона и текста нужно использовать в макете. Эта информация есть в проекте пиццерии.{% else %}Specify what background and text colour to use in the layout. This information is available in the pizzeria project.{% endif %}
  4. {% if lang == 'ru' %}Подготовьте или запросите перевод текста на локальный язык, если английский не основной язык в вашей стране.{% else %}Prepare or request translation of the text into the local language if English is not the main language in your country.{% endif %}

{% if lang == 'ru' %}1. Скачайте макет из папки Edit{% else %}1. Download the layout from Edit folder{% endif %}

{% if lang == 'ru' %}Все интерьерные постеры хранятся в папке Posters - v1.1. Скачайте макет постера Pizza slice и откройте его в Adobe Illustrator. Чтобы отредактировать его, вам понадобится файл Edit.{% else %}All interior posters are stored in the “Posters - v1.1” folder. Download the Pizza slice poster layout and open it in Adobe Illustrator. You will need an “Edit” file to edit it.{% endif %}

{% if lang == 'ru' %}2. Определите язык{% else %}2. Determine the language{% endif %}

{% if lang == 'ru' %}Мы предоставляем макеты с текстом на английском языке. Если в вашей стране английский не основной язык, переведите текст на локальный язык.{% else %}We provide layouts with text in English. If English is not the primary language in your country, translate the text into your local language.{% endif %}

{% if lang == 'ru' %}3. Выберите цвет текста и вставьте перевод{% else %}3. Select text colour and paste translation{% endif %}

{% if lang == 'ru' %}В слое с текстом есть два подслоя — Black и White. Выберите вариант нужного цвета, лишний слой удалите. Какой цвет текста использовать, указано в проекте пиццерии.{% else %}The text layer has two sub-layers, “Black” and “White”. Select the option of the necessary colour, remove the extra layer. Which text colour to use is specified in the pizzeria project.{% endif %}

{% if lang == 'ru' %}Вставьте перевод в соответствующие блоки по аналогии с англоязычной версией. Если после перевода количество строк в текстовом блоке увеличилось, вытяните блок так, чтобы поместилась вся фраза.{% else %}Insert the translation into corresponding blocks just the way they are in the English version. If the number of lines in the text block has increased after the translation, stretch the block to fit the entire phrase.{% endif %}

{% if lang == 'ru' %}При необходимости переместите нижний текстовый блок, сохраняя расстояние между блоками таким же, как в англоязычной версии.{% else %}If necessary, move the bottom text block, keeping the spacing between blocks the same as in the English version.{% endif %}

{% if lang == 'ru' %}Текст не должен выглядеть рваным по правому краю. Выровняйте его, чтобы он не заходил на два последних столбца сетки.{% else %}The text should not look jagged on the right edge. Align it so that it does not go over the last two columns of the grid.{% endif %}

{% if lang == 'ru' %}4. Замените порядковый номер пиццерии{% else %}4. Change serial number of the pizzeria{% endif %}

{% if lang == 'ru' %}Каждая пиццерия в сети «Додо Пиццы» имеет свой порядковый номер. Уточните, какой по счету была открыта ваша пиццерия, и замените номер на макете.{% else %}Each pizzeria in the Dodo Pizza network has its own serial number. Find out what number your pizzeria was opened with and replace the number on the layout.{% endif %}

{% if lang == 'ru' %}5. Расставьте акценты в тексте{% else %}5. Put accents into the text{% endif %}

{% if lang == 'ru' %}В макете постеров мы используем вариативный шрифт. В англоязычной версии основной текст мы набрали шрифтом в начертании Semi condensed (ширина 200), отдельные фразы сделали акцентными — установили начертание Expanded (ширина 500) для названия бренда «Dodo Pizza», слова «world» и порядкового номера пиццерии. Попробуйте сохранить акценты при переводе; проверьте, не мешают ли они воспринимать текст.{% else %}The font we use in the poster layout may vary. In the English version, we type the main text in Semi condensed font (width 200), and accentuate some phrases: we set the Expanded font (width 500) for the brand name "Dodo Pizza", the word "world" and the pizzeria's serial number. Try to secure these accents when translating; check if they do not interfere with the perception of the text.{% endif %}

{% if lang == 'ru' %}Если в вашем языке слова намного длиннее, чем в английском, сделайте акцент только на цифре — выделите порядковый номер пиццерии начертанием шрифта Expanded, а остальной текст оставьте без изменений.{% else %}If the words in your language are significantly longer than in English, emphasize only the number: highlight the pizzeria's serial number in Expanded font and leave the rest of the text unchanged.{% endif %}

{% if lang == 'ru' %}6. Выберите цвет фона{% else %}6. Select the background colour{% endif %}

{% if lang == 'ru' %}В слое Background выберите цвет, который указан в проекте пиццерии.{% else %}In the Background layer, select the colour that is specified in the pizza shop project.{% endif %}

{% if lang == 'ru' %}7. Объедините слои{% else %}7. Merge layers{% endif %}

{% if lang == 'ru' %}Проверьте, что в слое Text и Backgroung остались только те элементы, которые будут напечатаны — текст и фон, предусмотренные проектом. Перенесите подслой с текстом используемого цвета в слой Background, а все скрытые слои удалите.{% else %}Make sure that the “Text” and “Background” layers contain only the elements that will be printed - the text and the background, as specified by the project. Transfer the sublayer with the text of the colour you want to use to the “Background” layer, and delete all hidden layers.{% endif %}

{% if lang == 'ru' %}Выделите слой Background и растрируйте его. Для этого выберите в меню в верхней части экрана пункт Object - Rasterize. В диалоговом окне проверьте пункт Resolution: растрируйте макет в высоком разрешении 300 ppi.{% else %}Select the “Background” layer and rasterize it. To do this, choose Object - Rasterize from the menu at the top of the screen. In the dialog box, check the Resolution option: rasterize the layout at a high resolution of 300 ppi.{% endif %}

{% if lang == 'ru' %}8. Сохраните макет{% else %}8. Save the layout{% endif %}

{% if lang == 'ru' %}Сохраните макет в формате Adobe PDF (pdf) с помощью пресета, измените окончание в названии файла с Edit на Print.{% else %}Save the layout in Adobe PDF (pdf) format using the preset, change the end of the file name from “Edit” to “Print”.{% endif %}

{% if lang == 'ru' %}На экране появится диалоговое окно. Проверьте настройки pdf-файла:{% else %}A dialog box will appear on the screen. Check the settings of the pdf file:{% endif %}

  • {% if lang == 'ru' %}Стиль Adobe PDF: выбран пресет Fogra_39_print.{% else %}Adobe PDF style: Fogra_39_print preset is selected.{% endif %}
  • {% if lang == 'ru' %}Метки и выпуск за обрез: включена опция «Использовать параметры функции “Обрез документа”» и выставлены значения 50 мм для всех сторон. Это важно, так как постеры натягиваются на подрамник: края загибают, чтобы закрыть торцы.{% else %}Marks and Crop Issue: the “Use Document Crop Options” option is enabled and 50 mm is set for all sides. This is important because posters are pulled on a stretcher: the edges are creased to cover the ends.{% endif %}
  • {% if lang == 'ru' %}Вывод: в поле «Целевое пространство» указан «Документ CMYK - Coated FOGRA39».{% else %}Output: the “Target Space” field specifies “CMYK Document - Coated FOGRA39”.{% endif %}

{% if lang == 'ru' %}9. Готово!{% else %}9. Done!{% endif %}

{% if lang == 'ru' %}Теперь макет готов к передаче в типографию. Отправьте специалистам на производстве файл Print.{% else %}Now the layout is ready to be sent to the printing house. Send the “Print” file to the production specialists.{% endif %}
