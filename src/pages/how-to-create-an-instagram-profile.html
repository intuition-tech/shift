{% if lang == 'ru' %}Создаем страницу в Инстаграме{% else %}How to create an Instagram profile{% endif %}

{% if lang == 'ru' %}Когда Додо открывается в новой стране, мы создаём ещё одну страницу в Инстаграме. Там анонсируем открытие и продвигаем пиццерию. Рекомендуем создавать один аккаунт на страну.{% else %}When Dodo opens in a new country, we launch another profile on Instagram. This is the place where we announce the opening and promote the pizzeria. We recommend that you create one account per country.{% endif %}

{% if lang != 'ru' %}

It is really important to fill out all the fields correctly on this new page.

{% endif %}

{% if lang == 'ru' %}Заполняем имя. Пишем имя в формете «Dodo Pizza · Страна». Если название страны очень длинное, упрощаем. Например, для ОАЭ название будет «Dodo Pizza · UAE».{% else %}Fill in username. Its format is "Dodo Pizza - Country". If the name of the country is too long, make it shorter. For example, for the United Arab Emirates the name will be "Dodo Pizza - UAE".{% endif %}

{% if lang == 'ru' %}Адрес. Адрес будет почти таким же, как имя, только все буквы строчные — «dodopizza.страна». Например, адрес для ОАЭ — «dodopizza.uae».{% else %}Address. The address is almost the same as the name, but all the letters are lowercase - "dodopizza.country". For example, the address for the UAE - "dodopizza.uae".{% endif %}

{% if lang == 'ru' %}Аватар. На аватар аккаунта ставим круглый логотип Додо.{% else %}Avatar. Uploada round Dodo logo as an account avatar.{% endif %}

{% if lang == 'ru' %}Далее переходим в меню «Редактировать» справа от аватара и списываем остальную информацию.{% else %}Then go to the "Edit" menu to the right of the avatar and put down the rest of the information.{% endif %}

{% if lang == 'ru' %}Сайт. Каждая страна устанавливает свою ссылку.{% else %}Website. Each country sets its own link.{% endif %}

{% if lang == 'ru' %}О себе. Ещё этот раздел называют «био профиля». Здесь можно написать «International pizza chain now in…», добавить название страны и вставить ссылку на доставку. Например:{% else %}About ourselves. This section is also called "Bio". You can write "International pizza chain now in..." here, add the name of the country and insert the delivery link. For example:{% endif %}

«International pizza chain now in UAE. Order delivery: …»

{% if lang == 'ru' %}Переключаем аккаунт на профиль компании. Для этого:{% else %}Switch the profile to the business account. To do this:{% endif %}

  • {% if lang == 'ru' %}Переходим во вкладку Настройки → Аккаунт → Переключиться на профиль компании.{% else %}Go to Settings → Account → Switch to Professional Account.{% endif %}
  • {% if lang == 'ru' %}Инстаграм предложит создать страницу на Фейсбуке или пропустить этот шаг. Страничка понадобится для настройки таргета, поэтому лучше сразу создать её.{% else %}Instagram will prompt you to create a Facebook profile or skip this step. You will need the page to set up targeting, so it is better to create it right away.{% endif %}
  • {% if lang == 'ru' %}Указываем название страницы «Додо Пицца Страна». Например, в ОАЭ — «Додо Пицца ОАЭ». Категория — пиццерия.{% else %}Specify the name of the page "Dodo Pizza Country". For example, in the UAE - "Dodo Pizza UAE". Category - pizzeria.{% endif %}

{% if lang == 'ru' %}Заполняем информацию о компании и способы связи. Почта, телефон и адрес — индивидуальные поля, добавляем туда свои почту для сбора обратной связи, номер телефона и адрес — если пиццерий несколько, выбираем самую крупную.{% else %}Fill in information about the company and contact info. Mail, phone and address are individual fields, we add our mail to collect feedback, phone number and address. If there are several pizzerias, choose the largest.{% endif %}

{% if lang == 'ru' %}В «Личной информации» дублируем текст из раздела «О себе».{% else %}In the "Personal Information settings" duplicate the text from the "About Me" section.{% endif %}

{% if lang == 'ru' %}Готово, страничка создана. Теперь можно заполнять страницу контентом — о том, как это сделать, расскажем в следующих гайдах.{% else %}Done, the profile is created. Now you can fill in the content, we’re telling you how to do this in the upcoming guides.{% endif %}
