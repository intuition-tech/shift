{% if lang == 'ru' %}Готовим хиро-блок для меню в приложении{% else %}How to prepare a hero block for the application{% endif %}

{% if lang == 'ru' %}Разбираемся, как правильно сделать хиро-блоки для меню в приложении. В видео подробная инструкция с примерами на 20 минут. Ниже — саммари текстом.{% else %}Let's take a look at how proper hero blocks for the menu in our application are created. This video gives a 20-minute in-depth tutorial with examples. The following is a written summary of the video.{% endif %}

{% if lang == 'ru' %}Как все устроено{% else %}How it works{% endif %}

{% if lang == 'ru' %}Хиро — это блоки с продуктом в меню приложения, вот как они выглядят.{% else %}Hero blocks are items demonstrating a product on the application menu. Here's what they look like.{% endif %}

{% if lang == 'ru' %}Хиро-блок состоит из двух главных частей: картинки с продуктом и плашки с текстом.{% else %}The hero block consists of two main parts: a product image and a text plate.{% endif %}

{%- if lang == 'ru' %}Картинка с продуктом{% else %}Product image{% endif -%}
{%- if lang == 'ru' %}Плашка с текстом{% else %}Text plate{% endif -%}

{% if lang == 'ru' %}Нижняя часть, где отображается текст, создаётся автоматически на стороне приложения.{% else %}The lower part, where the text is displayed, is created automatically by the application itself.{% endif %}

{% if lang == 'ru' %}Промо-блок выглядит одинаково на светлой и темной теме, так что для картинки нужно подобрать такой цвет, который будет здорово смотреться в обоих случаях.{% else %}The promo block looks identical on both light and dark themes, so you need to find a colour for the image that will look great in either theme.{% endif %}

{% if lang == 'ru' %}Размеры картинки с продуктом всегда одинаковые, для мобильной версии 351×306 пикселей, для декстопа — 233×233 пикселя. В первой версии гайда объясняем все на примере картинки для мобильной версии.{% else %}The dimensions of product images are unified: 351×306 pixels for the mobile app and 233×233 pixels for the desktop view. In the first version of the guide, we break down how they are created giving an example with the image for the mobile app.{% endif %}

{% if lang == 'ru' %}Хиро по форме и наполнению могут быть очень разными — разберём в деталях, как их делать.{% else %}Hero blocks can vary significantly in form and content so let's take a closer look at how to make them.{% endif %}

{% if lang == 'ru' %}Фон и цвет{% else %}Background and colour{% endif %}

{% if lang == 'ru' %}Фон картинки с продуктом готовим сами, фон для плашки с текстом определяется автоматически на стороне приложения — но на его отображение можно повлиять.{% else %}We prepare the background for the product image ourselves, while the background for the text plate is created automatically in the application. However, its presentation can be altered.{% endif %}

{% if lang == 'ru' %}Фон для продукта. Продукт может быть на текстурном или однотонном фоне. Чаще всего мы используем фото.{% else %}Background for the product. The product can be placed on a plain background or the one with texture. We stick to using photos most times.{% endif %}

{% if lang == 'ru' %}Если фото нет, делаем однородный фон. Для обычных хиро без коллабораций выбираем цвет по категории продукта: серый для напитков, розовый для десертов, коричневый — для всего остального.{% else %}If there is no photo, we create a uniform background. For regular hero blocks without any collaborations, we pick a colour based on the product category: grey for drinks, pink for desserts, brown for the remaining part.{% endif %}

{% if lang == 'ru' %}Фон плашки с текстом. Определяется автоматически на стороне приложения по нижнему пикселю картинки с продуктом. Поэтому от нижнего края картинки отступаем полоску в 2 пикселя и заливаем её однотонным цветом — этот цвет и станет фоном плашки с текстом.{% else %}Background for text plates. This one is made automatically in the application based on the bottom pixel of the product image. Therefore, we leave a 2-pixel strip from the bottom edge of the image and fill it with a solid colour. This colour will be set as the background for the text plate.{% endif %}

{%- if lang == 'ru' %}Самый нижний последний пиксель{% else %}The last pixel on the very bottom{% endif -%}

{% if lang == 'ru' %}Cлишком яркие и светлые оттенки не берем. В темной и светлой темах текст и кнопки всегда белые — поэтому нам нужен контрастный цвет, который не будет сливаться.{% else %}We don't use shades that are overly bright or too light. With dark and light themes, the text and buttons are always white, so we need a contrasting colour that won't blend in.{% endif %}

{% if lang == 'ru' %}Нет{% else %}No{% endif %}

{% if lang == 'ru' %}Текст не читается, слишком светый фон{% else %}The text is hard to read, the background is too light{% endif %}

{% if lang == 'ru' %}Да{% else %}Yes{% endif %}

{% if lang == 'ru' %}Контрастный цвет фона, все видно{% else %}Contrasting background colour, everything is clear{% endif %}

{% if lang == 'ru' %}Проверяем контрастность фона на сайте get-color.ru. Максимальная яркость цвета — 0,83 единицы.{% else %}We go to website get-color.ru to verify background contrast. The maximum colour brightness is 0.83 units.{% endif %}

{% if lang == 'ru' %}Не берем для фона цвета тегов.{% else %}We do not use tag colours for the background.{% endif %}

{% if lang == 'ru' %}Тогда они сливаются с фоном — и картинка выглядит некрасиво.{% else %}If we did so, they would blend in with the background, and the image would look unattractive.{% endif %}

{% if lang == 'ru' %}Нет{% else %}No{% endif %}

{% if lang == 'ru' %}Не очень{% else %}Not really{% endif %}

{% if lang == 'ru' %}Да{% else %}Yes{% endif %}

{% if lang == 'ru' %}Теперь супер{% else %}Now it's great{% endif %}

{% if lang == 'ru' %}Переход. Этот пункт можно пропустить, если у вашего хиро однородный фон без фото и текстур. Если текстуры есть — обязательно делаем градиент, чтобы связать картинку с продуктом и плашку с текстом через плавный переход.{% else %}Transition. You can skip this step if your hero block has a uniform background that does not contain any photos or textures. If there are ones though, make sure to create a gradient to connect the image with the product and the text with the plate through a smooth transition.{% endif %}

{% if lang == 'ru' %}Нет{% else %}No{% endif %}

{% if lang == 'ru' %}Перехода нет, текстура на картинке резко обрывается, выглядит неаккуратно{% else %}There is no transition, the texture in the image breaks off abruptly and looks sloppy.{% endif %}

{% if lang == 'ru' %}Да{% else %}Yes{% endif %}

{% if lang == 'ru' %}Есть плавный переход через градиент, картинка вместе с текстом выглядят цельно{% else %}There is a smooth transition through the gradient, and the image and text look cohesive.{% endif %}

{% if lang == 'ru' %}Чтобы сделать градиент, берем цвет нижнего пикселя и растягиваем его от плашки вверх минимум на 30 пикселей.{% else %}To create a gradient, take the colour of the bottom pixel and stretch it upwards from the template by at least 30 pixels.{% endif %}

{% if lang == 'ru' %}Следим за тем, чтобы градиент подходил по цвету к картинке с продуктом и не был слишком резким. Растяжку можно увеличить, если хочется, 30 px — это минимальная высота. Главное, чтобы градиент не заходил на сам продукт.{% else %}Make sure that the gradient matches the colour of the product image and is not too sharp. You can make the stretch larger if you need; 30 px is the minimum height. The key is that the gradient does not overlap the product itself.{% endif %}

{% if lang == 'ru' %}Нет{% else %}No{% endif %}

{% if lang == 'ru' %}Слишком резко{% else %}Too sharp{% endif %}

{% if lang == 'ru' %}Да{% else %}Yes{% endif %}

{% if lang == 'ru' %}Плавно, хорошо{% else %}Smooth, looks good{% endif %}

{% if lang == 'ru' %}Верхняя форма блока{% else %}Upper block shape{% endif %}

{% if lang == 'ru' %}Есть два вида верхних форм: прямоугольная арка и овальная.{% else %}There are two types of upper blocks: rectangular arch and oval.{% endif %}

{% if lang == 'ru' %}Прямоугольная{% else %}Rectangular{% endif %}

{% if lang == 'ru' %}Овальная{% else %}Oval{% endif %}

{% if lang == 'ru' %}Высоту арок можно регулировать, при этом сам продукт сохраняет свои пропорции и расположение. Края продукта могут как бы «вылетать» за пределы арок.{% else %}The height of the arches can be adjusted, while the product itself retains its proportions and position. The edges of the product may protrude the arch edges.{% endif %}

{% if lang == 'ru' %}Прямоугольная арка. Форма со скруглением по бокам в 24 единицы. Диапазон высоты 180–306 пикселей.{% else %}Rectangular arch. This is a block with 24 units of rounding on the sides. The height ranges from 180 to 306 pixels.{% endif %}

{% if lang == 'ru' %}Овальная арка. Скругление 200 единиц, диапазон высоты 243–306 пикселей.{% else %}Oval arch. It is rounded on both sides by 200 units; the height ranges from 243 to 306 pixels.{% endif %}

{% if lang == 'ru' %}Вылеты и обрез{% else %}Bleeds and crop{% endif %}

{% if lang == 'ru' %}Вылеты. Продукт и другие объекты могут «вылетать» за пределы арок. Рекомендуем делать такие вылеты — так хиро выглядит интереснее.{% else %}Bleeds. The product and other objects may extend beyond the arches. We even recommend making such bleeds since they make the design look catchier.{% endif %}

{% if lang == 'ru' %}Следим за размером продукта и не делаем его слишком маленьким.{% else %}Keep an eye on the size of the product and don't make it too small.{% endif %}

{% if lang == 'ru' %}Нет{% else %}No{% endif %}

{% if lang == 'ru' %}Много пустого пространства сверху, слишком маленький продукт{% else %}Too much empty space above, the product looks too small{% endif %}

{% if lang == 'ru' %}Да{% else %}Yes{% endif %}

{% if lang == 'ru' %}Продукт в центре и крупно, нет пустого пространства сверху{% else %}The product is positioned in the centre and is large, with no blank space above{% endif %}

{% if lang == 'ru' %}И вот как это выглядит в интерфейсе приложения.{% else %}And this is how it looks in the app interface.{% endif %}

{% if lang == 'ru' %}Нет{% else %}No{% endif %}

{% if lang == 'ru' %}Белая дыра в ленте, как будто что-то сломалось{% else %}A white hole in the feed looking as if something is broken{% endif %}

{% if lang == 'ru' %}Да{% else %}Yes{% endif %}

{% if lang == 'ru' %}Интерфейс выглядит красиво и гармонично{% else %}The interface looks beautiful and balanced.{% endif %}

{% if lang == 'ru' %}Никогда не делаем «вылеты» из фотографий с фоном.{% else %}We never crop photos with backgrounds.{% endif %}

{% if lang == 'ru' %}Вылетающие объекты могут заходить за пределы арки, но всегда должны помещаться в границы самого блока.{% else %}Although the objects may cross the edges of the arch, they must always be placed within the boundaries of the block itself.{% endif %}

{% if lang == 'ru' %}На макете может быть не заметно, что объекты вышли за пределы максимальной высоты. А в интерфейсе приложения картинка некрасиво обрезается.{% else %}It may not be visible on the layout that the objects have exceeded the maximum height. But in the application interface the image will be cropped untidy.{% endif %}

{% if lang == 'ru' %}Обрезы можно и даже нужно делать — вот несколько правил, чтобы они смотрелись хорошо.{% else %}Cropping is possible and even necessary so here are a few rules to make it look good.{% endif %}

{% if lang == 'ru' %}Обрез. Продукты можно показывать целиком или увеличивать и обрезать. Здесь нужно следить за местом обреза и не кропать продукт «в воздухе». Место обреза должно совпадать с границами блока.{% else %}Crop. Products can be displayed in full or zoomed in and cropped. With the latter, you need to pay attention to the cropping area and do not leave the product cut out ‘in the air’. The cropping area should coincide with the block boundaries.{% endif %}

{% if lang == 'ru' %}Нет{% else %}No{% endif %}

{% if lang == 'ru' %}Край продукта обрывается на белом фоне, «в воздухе», некрасиво{% else %}The edge of the product is cut off on a white background, ‘in the air’, which looks unattractive.{% endif %}

{% if lang == 'ru' %}Да{% else %}Yes{% endif %}

{% if lang == 'ru' %}Край продукта заходит в арку, красиво и аккуратно{% else %}The edge of the product extends into the arch, which looks nice and neat.{% endif %}

{% if lang == 'ru' %}Логотипы, текст, объекты{% else %}Logos, text, objects{% endif %}

{% if lang == 'ru' %}Мы не ставим текст на фото с продуктом. Исключение — логотипы. Это часть каллоборации, плюс логотипы не нужно переводить и адаптировать.{% else %}We do not place text on photos with products. The only exception is logos. They are a part of the collaboration. Additionally, logos do not need to be translated or adapted.{% endif %}

{% if lang == 'ru' %}Нет{% else %}No{% endif %}

{% if lang == 'ru' %}Текст на фото спорит с текстом на плашке, нельзя локализовать{% else %}The text on the photo conflicts with the text on the template; it cannot be localised.{% endif %}

{% if lang == 'ru' %}Да{% else %}Yes{% endif %}

{% if lang == 'ru' %}На фото нет текста: макет не перегружен, легко локализовать{% else %}There is no text on the photo: the layout is not overloaded and is easy to localise.{% endif %}

{% if lang == 'ru' %}Если делаем промо для коллаборации — размещаем на картинке логотип партнёра. Кроме продукта и логотипа можно добавить ещё 3–4 небольших объекта-атрибута кампании.{% else %}If we create a promotion for a collaboration, we place the partner's logo on the image. In addition to the product and logo, you can place 3 or 4 small objects that are attributed to the campaign.{% endif %}

{% if lang == 'ru' %}Нет{% else %}No{% endif %}

{% if lang == 'ru' %}Слишком много объектов, теряется фокус на продукте{% else %}Too many objects, the focus on the product is lost.{% endif %}

{% if lang == 'ru' %}Да{% else %}Yes{% endif %}

{% if lang == 'ru' %}Продукт хорошо видно, есть атрибуты коллаборации{% else %}The product is clearly visible, there are collaboration attributes.{% endif %}
