{% if lang == 'ru' %}Виды сторис в приложении{% else %}Types of in-app stories{% endif %}

{% include "pub-meta.html" %}

{% if lang == 'ru' %}В приложении мы запускаем разные виды сторис. В этом гайде описали те, которые используем чаще всего.{% else %}We post various different types of stories in the app. This guide talks about the ones we use most often.{% endif %}

{% if lang == 'ru' %}Продуктовые{% else %}Product stories{% endif %}

{% if lang == 'ru' %}Цель: переход и совершение заказа.{% else %}Objective: to draw attention to the product and initialize the order.{% endif %}

{% if lang == 'ru' %}Рассказываем о новых продуктах или делимся историей их создания.{% else %}We tell the user about new products or how they were created.{% endif %}

{% if lang == 'ru' %}В анонсах новых продуктов мы говорим про конкретные вкусовые качества продукта, а не про абстрактный чувственный опыт. Пользователь должен понять, какой продукт на вкус, и захотеть его попробовать.{% else %}With new foods announcements, we tend to reveal the specific taste of the product, not an abstract sensory description. The user should figure out what the product tastes like and get a nudge to try it out.{% endif %}

{% if lang == 'ru' %}Информационные{% else %}Informational stories{% endif %}

{% if lang == 'ru' %}Цель: рассказать о важных изменениях.{% else %}Objective: to communicate significant changes.{% endif %}

{% if lang == 'ru' %}Информируем об изменениях в работе, открытии новых пиццерий, обновлениях в приложении, пиках.{% else %}We report changes in operations, new pizzeria openings, updates in the app, rush hours.{% endif %}

{% if lang == 'ru' %}Пики — это периоды высокой нагрузки в пиццериях. Чаще всего они выпадают на праздники, когда люди делают много заказов, а кухня и курьеры сильно загружены.{% else %}Rush hours are periods of highest workload in pizzerias. Most often they happen on holidays, when people place a lot of orders and the kitchen and couriers are really busy.{% endif %}

{% if lang == 'ru' %}Говорим кратко, по-честному, без заигрывания с аудиторией. В срочных сторис с изменениями работы, нехваткой продуктов мы прямо сообщаем о ситуации и о том, что сейчас она решается, без нечетких формулировок. И по-возможности предлагаем решения для пользователя: заказать в другие промежутки времени или заранее, воспользоваться самовывозом и тому подобное.{% else %}We speak briefly, honestly, without flirting with the audience. In urgent stories with work hours changes or product shortages, we give straightforward information about the problem and the fact that it is now being solved, without any vague wording. And, if possible, we offer solutions to the user: to order at a different time or in advance, to pick the order from the pizzeria, and so on.{% endif %}

{% if lang == 'ru' %}Миссии{% else %}Mission stories{% endif %}

{% if lang == 'ru' %}Цель: привлечь пользователя к выполнению миссии.{% else %}Objective: to engage the user into completing the mission.{% endif %}

{% if lang == 'ru' %}Ежемесячная рубрика, в которой важно не столько рассказывать о самой миссии, сколько завлечь аудиторию перейти по кнопке. На сторис раскрываем контекст — расказываем, почему эту миссию прикольно выполнить именно сейчас. Текст брифа (то есть самой миссии) не повторяем, чтобы пользователь не читал одно и то же.{% else %}Monthly section in which it is important not so much to tell about the mission itself, but to nudge the audience to push the button. With stories like these, we reveal the context telling the users why it is cool to do this mission right now. We do not duplicate the text of the brief (i.e. the instruction to mission), so that the user does not have to read the same thing twice.{% endif %}

{% if lang == 'ru' %}Полезные фичи{% else %}Useful features stories{% endif %}

{% if lang == 'ru' %}Цель: рассказать о новых функциях в приложении и научить ими пользоваться.{% else %}Objective: to tell the users about new features in the app and teach them how to use them.{% endif %}

{% if lang == 'ru' %}Используем простые формулировки и делаем акцент на пользе, которую получит клиент, не углубляясь в технические подробности. Например, когда вводится функция «Курьер на карте», пользователю важно рассказать, что так он сможет планировать свое время. Как может выглядеть структура сторис с новыми функциями:{% else %}We do this through simple wording and emphasize the benefits the customer will get, without going deep into technical details. For example, when the “Courier on map” feature is introduced, it's important to tell the user that this way they will be able to plan their time more efficiently. Here is what the structure of stories with a new feature might look like:{% endif %}

  • {% if lang == 'ru' %}Прямая польза для пользователя.{% else %}Major benefit for the user.{% endif %}
  • {% if lang == 'ru' %}Почему это удобно.{% else %}Why it is so convenient.{% endif %}
  • {% if lang == 'ru' %}Технические особенности, как это сделать и включить.{% else %}Technical features: how to enable and use it.{% endif %}
  • {% if lang == 'ru' %}Пометки для дизайнера, какой элемент интерфейса прикрепить.{% else %}Notes for the designer on which UI element to attach.{% endif %}

{% if lang == 'ru' %}Бывает, что новые для нас фичи не являются новыми для пользователей, потому что у них уже есть опыт из других приложений. Например, функция отслеживания курьера на карте может быть уже знакома. В таком случае, проявление заботы будет не разжевывание подробностей, а краткое сообщение с целью экономии времени аудитории.{% else %}There are cases when features that are new to us are not actually a novelty to our users because they already have this experience with other apps. For example, the courier tracking feature is something they may already be familiar with. In a situation like this, the manifestation of care would not be spoon-fed to the user, but rather presented as a brief, time-saving message.{% endif %}

{% if lang == 'ru' %}К разработке этого вида сторис подключается UX-редактор и на этапе получения брифа, и после того, как будут готовы первые тексты.{% else %}A UX editor is involved in the development of this type of stories both at the stage of receiving the brief and after the first texts are ready.{% endif %}

{% if lang == 'ru' %}Статистика{% else %}Statistics stories{% endif %}

{% if lang == 'ru' %}Цель: показать статистику, удивить, напомнить, что мы большой бренд.{% else %}Objective: to show figures, to surprise, to ensure the fact that we are a big brand.{% endif %}

{% if lang == 'ru' %}Один из вариантов сторис со статистикой — рубрика «Число месяца». Обычно состоит из одного слайда. Это могут быть данные о количестве съеденных за месяц Додстеров, среднем времени доставки или выдачи. В общем, любые факты, связанные с цифрами, которые могут произвести вау-эффект на пользователя.{% else %}One of the options for the stories with statistics is the heading “Figure of the month”. It usually consists of one slide. It can be data about the number of Dodsters eaten during the month, average delivery or giveaway time. In general, any facts related to stats that can produce a wow effect on the user.{% endif %}

{% if lang == 'ru' %}Лена Пирог рассказывает, как найти интересные данные.{% else %}Lena Pirog talks about how to find interesting data.{% endif %}

{% if lang == 'ru' %}Работа в Додо{% else %}Job offers at Dodo stories{% endif %}

{% if lang == 'ru' %}Цель: привлечение новых сотрудников.{% else %}Objective: to attract new employees.{% endif %}

{% if lang == 'ru' %}Рассказываем о вакансиях, формируем HR-бренд, делимся историями работников Додо.{% else %}We tell about job positions, build an HR-brand, share Dodo employees’ stories.{% endif %}

{% if lang == 'ru' %}При написании сторис ориентируемся на тональность сайта «Работа в Додо». Основная идея: «Для нас важен каждый. В Додо есть то, что важно».{% else %}When making these, we are guided by the Work at Dodo website. The key idea is this: “Everyone is important to us. Dodo has what is important”.{% endif %}

{% if lang == 'ru' %}Познавательные{% else %}Educational stories{% endif %}

{% if lang == 'ru' %}Цель: научить новому с помощью полезных подборок, инструкций, ответов на вопросы и чек-листов.{% else %}Objective: to teach new things with helpful selections, instructions, answers to questions and checklists.{% endif %}

{% if lang == 'ru' %}Например, сторис c фактами месяца.{% else %}For example, a story of the month fact sheet.{% endif %}

{% if lang == 'ru' %}Видео и motion-сторис{% else %}Video and motion stories{% endif %}

{% if lang == 'ru' %}Цель: показать живую картинку, привлечь внимание пользователя через интересный формат.{% else %}Objective: to show a live picture, to grab the user's attention through an interesting format.{% endif %}

{% if lang == 'ru' %}В написании сценария видео, титров, текста для спикера или закадрового голоса опираемся на тональность бренда.{% else %}In writing the script of the video, credits, text for the speaker or voice-over, we rely on the brand’s tone of voice.{% endif %}

{% if lang == 'ru' %}Вовлекающие{% else %}Engaging stories{% endif %}

{% if lang == 'ru' %}Цель: повзаимодействовать с пользователем и по возможности собрать обратную связь.{% else %}Objective: to engage with the user and gather feedback where possible.{% endif %}

{% if lang == 'ru' %}Взаимодействуем через опросы, вопросы, квесты и тесты.{% else %}Engage through surveys, questions, quests and tests.{% endif %}

{% if lang == 'ru' %}Развлекательные{% else %}Entertaining stories{% endif %}

{% if lang == 'ru' %}Цель: поддержать интерес аудитории.{% else %}Objective: to keep the audience locked in.{% endif %}

{% if lang == 'ru' %}Публикуем игры, подбороки и истории.{% else %}Here we post games, selections and stories.{% endif %}
