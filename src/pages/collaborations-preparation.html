{% if lang == 'ru' %}Подготовительный этап{% else %}Preparation stage{% endif %}

{% if lang == 'ru' %}Поиск партнёров, лицензия и контракт, тайминг проекта и прогноз продаж.{% else %}Finding partners, license and contract, project timing and sales forecast.{% endif %}

{% if lang == 'ru' %}С подготовки начинается любая коллаборация, ещё до переговоров с партнёром. Мы ищем и отбираем бренды, формируем бриф и критерии выбора, а параллельно раскладываем верхнеуровневый роадмап с учётом ограничений логистики и производства.{% else %}Every collaboration starts with preparation, before we even talk to a partner. We search for and shortlist brands, shape the brief and selection criteria, and at the same time map out a high-level roadmap accounting for logistics and production constraints.{% endif %}

{% if lang == 'ru' %}Выбираем франшизу по пяти принципам{% else %}Choose the franchise by five principles{% endif %}

{% if lang == 'ru' %}Это верхнеуровневые принципы, которыми мы руководствуемся на начальном этапе, чтобы обозначить рамки коллаборации.{% else %}These are high-level principles we follow at the initial stage to set the frame of the collaboration.{% endif %}

{% if lang == 'ru' %}1. Актуальность{% else %}1. Relevance{% endif %}

{% if lang == 'ru' %}Бренд-партнёр должен быть узнаваем: либо это широко известный бренд, либо у него есть вовлечённое фан-сообщество, готовое откликнуться на новинку. Хорошо, если в планах у партнёра есть значимые события или инфоповоды: так мы сможем усилить эффект от коллаборации для обеих сторон. А если бренд сейчас не на пике известности, но совпадает с актуальными трендами — например, с ностальгией по 2000-м, которая вызывает тёплую реакцию при одном упоминании, — это тоже сильный кандидат для партнёрства.{% else %}The partner brand should be recognizable: either widely known, or with an engaged fan community ready to respond to a new release. It helps if the partner has significant events or news occasions planned: that way we can amplify the effect for both sides. And if the brand is not at peak fame right now but matches current trends — for example 2000s nostalgia, the kind that prompts a warm reaction at a mere mention — that is also a strong candidate.{% endif %}

{% if lang == 'ru' %}2. Новаторство{% else %}2. Innovation{% endif %}

{% if lang == 'ru' %}Мы действуем быстро и берём эффект первого появления на рынке. Ищем уникальные форматы и партнёрства, которых ещё не было, либо новый опыт лично для нас — даже если бренд уже запускал коллаборации с кем-то ещё. Именно новизна и смелость делают запуск запоминающимся.{% else %}We move fast and take the first-mover effect. We look for unique formats and partnerships that have not been on the market yet, or a new experience for us even if the brand has already collaborated with someone else. Novelty and boldness are what make a launch memorable.{% endif %}

{% if lang == 'ru' %}3. Попадание в аудитории{% else %}3. Audience fit{% endif %}

{% if lang == 'ru' %}Коллаборация должна быть актуальна для текущих гостей и сегментов, с которыми мы уже работаем, и одновременно открывать возможность привлечения новой аудитории. Точное попадание в интересы — обязательное условие.{% else %}The collaboration should be relevant for current guests and segments we already work with, and at the same time open a way to attract a new audience. A precise fit with interests is a mandatory condition.{% endif %}

{% if lang == 'ru' %}4. Аутентичность{% else %}4. Authenticity{% endif %}

{% if lang == 'ru' %}Франшиза должна совпадать с тем, кто мы как бренд. У каждого тайтла свои смыслы — их нужно соединить с Додо так, чтобы получился понятный продукт, в котором мы не теряем себя. Коллаборация может удивлять и выходить за привычный образ, но характер бренда, тон и то, как мы говорим с гостями, остаются нашими. Громкий тайтл сам по себе не достаточен: если его мир не пересекается с тем, что мы транслируем, запуск будет неаутентичным.{% else %}The franchise has to match who we are as a brand. Every title has its own meanings — we need to connect them with Dodo so the product is clear and we do not lose ourselves in it. A collaboration can surprise people and go beyond the familiar image, but the brand’s character, tone and how we talk to guests stay ours. A loud title is not enough on its own: if its world does not overlap with what we communicate, the launch will not be authentic.{% endif %}

{% if lang == 'ru' %}5. Доступность франшизы в стране{% else %}5. Franchise availability in the country{% endif %}

{% if lang == 'ru' %}Партнёр должен быть реально представлен и доступен для аудитории в стране — юридически, физически, культурно.{% else %}The partner must actually be present and accessible for the audience in the country — legally, physically, culturally.{% endif %}

{% if lang == 'ru' %}Ищем партнёра на рынке{% else %}Look for a partner on the market{% endif %}

{% if lang == 'ru' %}Когда мы определились с направлением коллаборации, можно переходить к поиску партнёров на рынке. Сначала мы смотрим, какие франшизы вообще доступны в стране, и начинаем предварительные переговоры с правообладателями. Так собираем пул лицензий на текущий календарный год: выясняем условия сотрудничества, эксклюзивность и ограничения, и заранее оцениваем, реально ли запустить проект и сколько это будет стоить.{% else %}When we have settled on the direction of the collaboration, we can look for partners on the market. First we look at which franchises are available in the country at all, and start preliminary talks with rights holders. That is how we assemble a pool of licenses for the current calendar year: we clarify terms, exclusivity and constraints, and estimate early on whether the project is feasible and what it will cost.{% endif %}

{% if lang == 'ru' %}Есть три пути, через которые мы выходим в лицензионные коллаборации.{% else %}There are three paths we take into licensed collaborations.{% endif %}

{% if lang == 'ru' %}1. Напрямую{% else %}1. Directly{% endif %}

{% if lang == 'ru' %}Ищем партнёров и ведём коммуникацию сами. Идём напрямую в студии и издательства: «Мельница», зарубежные разработчики вроде miHoYo (Genshin, ZZZ, Honkai). Это требует больше ресурсов и времени на контакт, зато нет агентской комиссии.{% else %}We look for partners and handle the communication ourselves. We go straight to studios and publishers: Melnitsa, and foreign developers such as miHoYo (Genshin, ZZZ, Honkai). It takes more time and resources to make contact, but there is no agency fee.{% endif %}

{% if lang == 'ru' %}2. Через агентства{% else %}2. Through agencies{% endif %}

{% if lang == 'ru' %}Скоринг берёт на себя агентство, оно выступает посредником между Додо и правообладателями и передаёт нам данные по рынку и доступ к международным и локальным проектам, которые готовы к сотрудничеству.{% else %}The agency takes on the scoring. It is a go-between for Dodo and rights holders and gives us market data and access to international and local projects that are ready to collaborate.{% endif %}

{% if lang == 'ru' %}3. Через продакшн-студии{% else %}3. Through production studios{% endif %}

{% if lang == 'ru' %}Иногда мы работаем с независимыми продакшн-студиями и стримингами — Кинопоиск, Start, Иви. Это путь к свежим сериальным и анимационным тайтлам.{% else %}Sometimes we work with independent production studios and streamers — Kinopoisk, Start, Ivi. This is the path to fresh series and animation titles.{% endif %}

{% if lang == 'ru' %}Какой бы путь мы ни выбрали, результатом этого этапа будет первичный пул франшиз, которые могут стать нашими партнёрами. Далее нам нужно оценить возможности для сотрудничества и отобрать самых подходящих кандидатов.{% else %}Whatever path we take, this stage ends with a primary pool of franchises that could become our partners. Next we need to assess the options for collaboration and shortlist the strongest candidates.{% endif %}

{% if lang == 'ru' %}Оцениваем и отбираем{% else %}Evaluate and shortlist{% endif %}

{% if lang == 'ru' %}Оцениваем франшизы из первичного пула: количественным тестом на аудитории и концепт-тестами. Тесты и анализ делают дата-аналитики и ресёрчеры. Затем сверяем кандидатов с критериями ниже и собираем финальный пул.{% else %}We evaluate the franchises in the primary pool: with a quantitative audience test and concept tests. Data analysts and researchers run the tests and the analysis. Then we check the candidates against the criteria below and assemble the final pool.{% endif %}

{% if lang == 'ru' %}Количественный тест аудитории{% else %}Quantitative audience test{% endif %}

{% if lang == 'ru' %}Проверяем гипотезы на целевых сегментах. Смотрим знание и охват: узнают ли тайтл в нужной возрастной группе. Смотрим активную базу: смотрели ли, играли, были ли фанатами; для ретро-франшиз — был ли опыт в детстве. Замеряем отношение: насколько восприятие позитивное или негативное. И отдельно смотрим намерение к покупке: готовы ли люди брать комбо с мерчем.{% else %}Then we test the hypotheses on target segments. We look at awareness and reach: whether people in the right age group know the title. We look at the active base: whether they watched, played, were fans; for retro franchises, whether they knew it as children. We measure attitude: how positive or negative the perception is. And we look separately at purchase intent: whether people are ready to buy a combo with merch.{% endif %}

{% if lang == 'ru' %}Концепт-тесты{% else %}Concept tests{% endif %}

{% if lang == 'ru' %}Для оценки партнёра проводим концепт-тесты: проверяем актуальность и намерение к покупке. Для теста готовим концепт продукта и запускаем опрос — интересно ли предложение и готовы ли его купить. Концепт показываем вместе с альтернативами, чтобы увидеть конкурентоспособность. Параллельно смотрим описание аудитории и собственную оценку — что ей близко.{% else %}To evaluate a partner we run concept tests: we check relevance and purchase intent. For the test we prepare a product concept and run a survey — whether the offer is interesting and whether people would buy it. We show the concept alongside alternatives to see competitiveness. In parallel we look at audience profiles and our own assessment of what is close to them.{% endif %}

{% if lang == 'ru' %}Партнёра оцениваем по критериям ниже.{% else %}We evaluate a partner against the criteria below.{% endif %}

{% if lang == 'ru' %}Релевантный эффект{% else %}Relevant effect{% endif %}

{% if lang == 'ru' %}Насколько тема откликнется у целевой аудитории и приведёт к продажам.{% else %}How well the theme will resonate with the target audience and drive sales.{% endif %}

{% if lang == 'ru' %}Виральный потенциал{% else %}Viral potential{% endif %}

{% if lang == 'ru' %}Насколько аудитория сама разнесёт новость, без больших вложений в продвижение. Смотрим способность продукта вызывать органический контент и распространение в соцсетях, попадание в тренды.{% else %}How much the audience will spread the news on its own, without heavy promotion spend. We look at whether the product can generate organic content and sharing on social, and whether it can hit trends.{% endif %}

{% if lang == 'ru' %}Конкурентоспособность{% else %}Competitiveness{% endif %}

{% if lang == 'ru' %}Не выбираем то, что уже запускалось у других и потеряло новизну. Стараемся быть первыми.{% else %}We do not choose what others have already launched and what has lost its novelty. We try to be first.{% endif %}

{% if lang == 'ru' %}Соответствие бренду{% else %}Brand fit{% endif %}

{% if lang == 'ru' %}Совпадают ли смыслы: о чём говорит мультфильм, фильм или игра, пересекается ли это с тем, что транслируем мы.{% else %}Whether the meanings align: what the show, film or game communicates, and whether it overlaps with what we communicate.{% endif %}

{% if lang == 'ru' %}Сила фан-базы{% else %}Fan-base strength{% endif %}

{% if lang == 'ru' %}Насколько преданная и активная аудитория стоит за брендом — готова ли она реагировать, обсуждать, покупать. Смотрим сплочённость и размер комьюнити и готовность вовлекаться в акции с любимыми героями.{% else %}How devoted and active the audience behind the brand is — whether it is ready to react, discuss and buy. We look at how tight and large the community is, and how ready they are to join campaigns with their favourite characters.{% endif %}

{% if lang == 'ru' %}Поисковый запрос{% else %}Search demand{% endif %}

{% if lang == 'ru' %}Объём запросов с учётом специфики проекта. У игр он традиционно выше, чем у фильмов или сериалов — учитываем это при сравнении. Смотрим, как часто франшизу ищут в поиске и соцсетях.{% else %}Search volume, adjusted for the type of project. Games traditionally score higher than films or series — we account for that when comparing. We look at how often people search for the franchise in search and social.{% endif %}

{% if lang == 'ru' %}Динамика тренда{% else %}Trend dynamics{% endif %}

{% if lang == 'ru' %}Бренд сейчас растёт, на пике или уже угасает — важно понимать, в какой фазе мы заходим. Растущий спрос — хороший знак, падающий — риск, что к запуску интерес уже снизится.{% else %}Whether the brand is growing, at its peak or already fading — we need to know which phase we are entering. Growing demand is a good sign; falling demand is a risk that interest will already have dropped by launch.{% endif %}

{% if lang == 'ru' %}Значимые события у партнёра в даты коллаборации{% else %}Partner events during the collaboration dates{% endif %}

{% if lang == 'ru' %}Есть ли релизы, премьеры, юбилеи или другие инфоповоды, которые совпадут по времени и усилят эффект. Чем таких поводов больше, тем сильнее можем усилить запуск.{% else %}Whether there are releases, premieres, anniversaries or other news occasions that will coincide in time and amplify the effect. The more of these occasions there are, the more we can amplify the launch.{% endif %}

{% if lang == 'ru' %}Уникальность{% else %}Uniqueness{% endif %}

{% if lang == 'ru' %}Насколько партнёрство свежее — работал ли бренд уже с похожими проектами, и что нового мы можем сделать вместе. Смотрим отстройку от конкурентов в QSR и свежесть предложения на российском рынке.{% else %}How fresh the partnership is — whether the brand has already worked with similar projects, and what new we can do together. We look at differentiation from QSR competitors and how fresh the offer is on the Russian market.{% endif %}

{% if lang == 'ru' %}Коммерческий потенциал{% else %}Commercial potential{% endif %}

{% if lang == 'ru' %}Насколько коллаборация может конвертироваться в продажи, трафик, выручку.{% else %}How far the collaboration can convert into sales, traffic and revenue.{% endif %}

{% if lang == 'ru' %}Визуальный потенциал для мерча{% else %}Visual potential for merch{% endif %}

{% if lang == 'ru' %}Насколько у бренда богатый визуальный язык — персонажи, цвета, символика, — который хорошо ляжет на продукцию. Гибкость стилистики важна для фигурок, брелоков, карточек и упаковки.{% else %}How rich the brand’s visual language is — characters, colours, symbols — and how well it will sit on the product. Flexibility of style matters for figures, keychains, cards and packaging.{% endif %}

{% if lang == 'ru' %}UGC / виральный потенциал{% else %}UGC / shareability{% endif %}

{% if lang == 'ru' %}Захочет ли аудитория сама создавать контент, делиться, отмечать — насколько тема «шерабельна».{% else %}Whether the audience will create content, share and tag on its own — how shareable the theme is.{% endif %}

{% if lang == 'ru' %}Легаси бренда{% else %}Brand legacy{% endif %}

{% if lang == 'ru' %}Уровень исторической значимости и узнаваемости бренда во времени.{% else %}The brand’s historical weight and recognizability over time.{% endif %}

{% if lang == 'ru' %}Стоимость и доступность лицензии в стране{% else %}License cost and availability in the country{% endif %}

{% if lang == 'ru' %}Если коллаборация подразумевает покупку прав — оцениваем цену и реальную возможность оформить лицензию в нашей юрисдикции.{% else %}If the collaboration involves buying rights — we assess the price and whether the license can actually be secured in our jurisdiction.{% endif %}

{% if lang == 'ru' %}Финальный пул{% else %}Final pool{% endif %}

{% if lang == 'ru' %}Финальный пул — это короткий список франшиз, которые прошли тест и оценку по критериям и из которых мы выбираем запуски. Решение принимаем в пользу франшизы с максимальным интегральным баллом по критериям и тесту намерений.{% else %}The final pool is a short list of franchises that passed the test and the criteria assessment, and from which we pick launches. The decision goes to the franchise with the highest combined score on the criteria and the intent test.{% endif %}

{% if lang == 'ru' %}Составляем тайминг и роадмап{% else %}Set the timing and roadmap{% endif %}

{% if lang == 'ru' %}Когда партнёр для коллаборации выбран, мы начинаем готовить роадмап. Это сводный план проекта: этапы, длительность работ и точки передачи между командами. Верхнеуровневый роадмап фиксирует коллаборацию в календарных рамках ещё до переговоров с производствами.{% else %}Once the collaboration partner is chosen, we start building the roadmap. It is a consolidated project plan: stages, duration of work and handoff points between teams. A high-level roadmap locks the collaboration into the calendar before we talk to manufacturers.{% endif %}

{% if lang == 'ru' %}Длительность каждого этапа считаем обратным ходом: намечаем дату старта и движемся назад. Обычно на одну коллаборацию от выбора партнёра до запуска закладывается один год.{% else %}We calculate the length of each stage in reverse: we set the launch date and count back. Usually we allow one year for a collaboration, from choosing the partner to launch.{% endif %}

{% if lang == 'ru' %}На этом этапе цифры всегда приблизительные, потому что мы ещё не знаем всех деталей коллаборации. Но заложить время на каждый шаг сейчас очень важно, чтобы успеть всё подготовить. По нашему опыту на каждый этап выходят примерно такие тайминги.{% else %}At this stage the numbers are always approximate, because we do not yet know all the details of the collaboration. But it is important to reserve time for each step now, so we can get everything ready. From our experience, the timings for each stage come out roughly like this.{% endif %}

{% if lang == 'ru' %}2 недели{% else %}2 weeks{% endif %}

{% if lang == 'ru' %}1. Стратегия{% else %}1. Strategy{% endif %}

{% if lang == 'ru' %}Собираем команды и брифуем на разработку стратегии: для какой аудитории запускаемся, какой продукт возможен, какие цели у проекта. Стратеги выделяют RTB и прорабатывают позиционирование коллаборации и продукта.{% else %}We gather the teams and brief them to develop the strategy: which audience we are launching for, what product is possible, what the project goals are. Strategists define the RTB and work through the positioning of the collaboration and the product.{% endif %}

{% if lang == 'ru' %}4 недели{% else %}4 weeks{% endif %}

{% if lang == 'ru' %}2. Креатив{% else %}2. Creative{% endif %}

{% if lang == 'ru' %}Когда стратегия согласована, креативная команда придаёт ей форму: какой это будет продукт, как он выглядит и как называется. Параллельно с самого начала сверяем идеи с операционкой пиццерий. Команда креатива подключается не только на этапе разработки концепции, но и на этапах упаковки и мерча.{% else %}Once the strategy is approved, the creative team gives it form: what the product will be, how it looks and what it is called. In parallel we check ideas with pizzeria operations from the very start. The creative team stays involved not only during concept development, but also during packaging and merch.{% endif %}

{% if lang == 'ru' %}2 месяца производства + 2 недели на разработку{% else %}2 months production + 2 weeks for development{% endif %}

{% if lang == 'ru' %}3. Упаковка{% else %}3. Packaging{% endif %}

{% if lang == 'ru' %}Вёрстаем уникальную упаковку, готовим комплексное предложение, которое выделяется. Брифуем внутреннюю команду, передаём дизайн — они ищут поставщиков и проводят мини-тендер.{% else %}We lay out unique packaging and prepare a comprehensive offer that stands out. We brief the internal team and hand off the design — they find suppliers and run a mini-tender.{% endif %}

{% if lang == 'ru' %}4 месяца{% else %}4 months{% endif %}

{% if lang == 'ru' %}4. Мерч{% else %}4. Merch{% endif %}

{% if lang == 'ru' %}По бюджету и срокам выбираем форм-фактор, прорабатываем дизайн и отправляем лицензиару на согласование. Упаковка и мерч идут параллельно.{% else %}We choose the form factor by budget and timeline, work through the design and send it to the licensor for approval. Packaging and merch run in parallel.{% endif %}

{% if lang == 'ru' %}Оформляем лицензию и контракт{% else %}Secure the license and contract{% endif %}

{% if lang == 'ru' %}Параллельно с роадмапом мы занимаемся покупкой лицензии и подписанием контракта.{% else %}In parallel with the roadmap we buy the license and sign the contract.{% endif %}

{% if lang == 'ru' %}Сначала нужно выбрать формат сотрудничества. От него зависит, как будет устроена экономика коллаборации и какие права нам нужно купить. В коллаборациях мы выделяем два вида сотрудничества.{% else %}First we need to choose the partnership format. It decides how the collaboration economics work and which rights we need to buy. In collaborations we distinguish two kinds of partnership.{% endif %}
