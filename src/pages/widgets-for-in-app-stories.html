{% if lang == 'ru' %}Виджеты и механики геймификации{% else %}Widgets and gamification mechanics{% endif %}

{% if lang == 'ru' %}Примеры виджетов и механик геймификации, а также инструкция по их добавлению в сторис.{% else %}Widgets and gamification mechanics with examples, and instructions on how to add them to stories.{% endif %}

{% if lang == 'ru' %}Используем виджеты, когда хотим геймифицировать контент, получить обратную связь от клиентов и увеличить вовлеченность.{% else %}We enable widgets when we want to gamify content, get feedback from customers and increase their engagement.{% endif %}

{% if lang == 'ru' %}Если во время разработки сторис пришла идея добавить виджет:{% else %}If you come up with the idea to add a widget while developing stories:{% endif %}

  • {% if lang == 'ru' %}описываем его механику в комментариях к слайду;{% else %}describe its mechanics in the comments to the slide;{% endif %}
  • {% if lang == 'ru' %}не перегружаем сторис текстом, чтобы хватило места для виджета.{% else %}do not overload the stories with text information, to save enough space for the widget.{% endif %}

{% if lang == 'ru' %}Виды и функции виджетов{% else %}Types and functions of widgets{% endif %}

{% if lang == 'ru' %}Тест с выбором правильного ответа. Используем для квизов и тестов, когда хотим вовлечь пользователей и сохранить интригу. Если вопросы сложные, можно добавить подсказки прямо в виджет.{% else %}A quiz with multiple choice answers. We use it when we want to engage users and create an intriguing narrative. If the questions are tricky, you can add clues directly into the widget.{% endif %}

{% if lang == 'ru' %}Окно для ответа. Собираем обратную связь или вопросы клиентов.{% else %}Response box. Used to collect feedback or questions from customers.{% endif %}

{% if lang == 'ru' %}Вопрос с выбором из двух вариантов. Спрашиваем мнение пользователей, проводим несложную игру.{% else %}A question with a choice of two options. Used to ask for users' opinion, run a simple game.{% endif %}

{% if lang == 'ru' %}«Тянучка» с выбором реакции-эмодзи. Предлагаем пользователям поделиться впечатлениями.{% else %}‘Stretch’ with a selection of emoji reactions. We call in our users to share their impressions.{% endif %}

{% if lang == 'ru' %}Голосование. Выбираем фаворитов, узнаём мнение аудитории.{% else %}Vote. Choose favorites, find out what the audience thinks.{% endif %}

{% if lang == 'ru' %}Оценка. Просим поставить оценку вкусу или новой продуктовой идее. Например, попросить проголосовать за вкус новой пиццы.{% else %}Rating. Ask to rate a flavor or a new product idea. For example, ask to vote for a new pizza flavor.{% endif %}

{% if lang == 'ru' %}Обратный отсчет. Таймер, который поможет анонсировать событие или выход новинки.{% else %}Countdown. A timer to announce an event or release of a new product.{% endif %}

{% if lang == 'ru' %}Кнопка со ссылкой. Оставь пользователям прямую ссылку на продукт, промокод или лендинг и не забудь добавить call to action. Кнопки существуют двух видов, смотри примеры ниже.{% else %}Link button. Provides the users with a direct link to a product, promo code or lending. Don't forget to add a call to action. There are two types of buttons: see examples below.{% endif %}

{% if lang == 'ru' %}Нотификация. Не является виджетом, но ее почти всегда можно добавить. Это сообщение, которое увидит пользователь после взаимодействия с виджетом. Если нужно о чем-то напомнить и сделать это интересно, используем ее.{% else %}Notification. Not a widget, but it can almost always be applied. It is a message that the user will see after interacting with the widget. If you need to remind the users about something and make it interesting, go for it.{% endif %}

{% if lang == 'ru' %}Более детально ознакомиться с виджетами и примерами их использования можно на сайте innappstory.com. Для этого получите доступ у оунера сторис Айназа и зайдите на сайт в раздел Ресурсы — Использование виджетов.{% else %}To learn more about widgets and examples of how to use them, visit innappstory.com. To do this, get access from Ainaz’s story owner and go to the Resources - Using Widgets section of the site.{% endif %}

{% if lang == 'ru' %}Механики геймификации{% else %}Gamification mechanics{% endif %}

{% if lang == 'ru' %}«Открытки». Позволяет поднять узнаваемость бренда и придать виральность отдельным инфоповодам. Пользователь может выбрать одно из заранее подготовленных изображений. Добавить к нему свой текст и поделиться получившейся открыткой в соцсетях или мессенджерах.{% else %}Postcards. Allow to raise brand awareness and push the selected info promotions to go viral. The user can pick one of the image templates, add their own capture to it and share the resulting postcard on social networks or messengers.{% endif %}

{% if lang == 'ru' %}«Колесо фортуны». Позволяет проводить быстрые розыгрыши небольших призов среди клиентов приложения. Игровой процесс очень прост: пользователь запускает колесо, оно крутится и постепенно останавливается на одном из секторов. Если на секторе размещен приз, откроется дополнительная страница с его описанием и способом получения. Если сектор пустой, то и приз отсутствует.{% else %}Wheel of fortune. Allows for quick draw of small prizes among the application users. The mechanics is very simple: the user turns the wheel, it spins and gradually stops on one of the sections. If there is a prize section, a new page will open with its description and the way to get it. If the section is empty, there is no prize.{% endif %}

{% if lang == 'ru' %}«Пятнашки». Рассчитана на быстрый розыгрыш какого-то одного приза — например, промокода. Это логическая игра: пользователь должен собрать картинку, перемещая ее части. Количество частей, на которые делится изображение, опционально. Можно ограничить время на игру или количество ходов. В игре можно либо выиграть, либо проиграть. Повторные попытки на прохождение не предусмотрены.{% else %}Spots. It is designed for a quick draw of a single prize, for example, a promo code. This is a logical game: the user must assemble a picture by moving its parts. The number of parts into which the image is divided is optional. You can limit the time for the game or the number of moves. The game can either be won or lost. There is no second attempt given.{% endif %}

{% if lang == 'ru' %}«Мемориз». Рассчитана на быстрый розыгрыш какого-то одного приза — например, промокода. Это игра на запоминание: пользователь должен запомнить расположение карточек и собрать все пары повторяющихся картинок (во время игры карточки находятся рубашками вверх). Количество пар можно выбрать в настройках, их может быть 8 или 10. Помимо этого, можно ограничить время на игру или количество ходов. В игре можно либо выиграть, либо проиграть. Регулярность выдачи бесплатных повторных попыток на прохождение можно настроить.{% else %}Memories. It is designed for a quick draw of a single prize, for example, a promo code. This is a memorisation game: the user must remember the location of the cards and collect all pairs of repeating pictures (during the game the cards are face down). The number of pairs can be selected in the settings, 8 or 10. In addition, you can limit the time for the game or the number of moves. In the game you can either win or lose. The regularity of free retries can be customized.{% endif %}
