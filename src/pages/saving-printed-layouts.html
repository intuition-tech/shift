{% if lang == 'ru' %}Сохраняем печатные макеты{% else %}Saving printed layouts{% endif %}

{% if lang == 'ru' %}Подготовка к сохранению макетов на печать{% else %}Preparing to save layouts for printing{% endif %}

{% if lang == 'ru' %}Прежде чем сохранять макет, редактируем лигалы и ценники, устанавливаем пресеты и определяем формат макета.{% else %}Before saving a layout, we edit legal information and price tags, set presets and indicate the layout format.{% endif %}

  1. {% if lang == 'ru' %}

    Скачиваем макет для редактирования

    В Базе знаний это кнопка For Editing. Она ведет на папку с макетом в формате .ai.

    {% else %}

    Download a layout for editing

    You will find it under the “For Editing” button in the Knowledge base. It brings you to the folder with the layout in .ai format.

    {% endif %}
  2. {% if lang == 'ru' %}

    Открываем макет в Adobe Illustrator

    Если программа выдает ошибки, связанные со шрифтами, скачиваем шрифты еще раз и переустанавливаем. Такое может произойти, если до этого мы обновили шрифт, но в программе осталась предыдущая версия. Скачать шрифты можно в Брендбуке.

    {% else %}

    Open the layout in Adobe Illustrator

    If Adobe software indicates errors related to fonts, download the fonts again and reinstall them. This can happen if we have updated the font before, but the program still contains the previous version. You can download fonts from the Brand book.

    {% endif %}
  3. {% if lang == 'ru' %}

    Редактируем макет

    Если нам нужно отредактировать юридическую информацию, выбрать ценовую группу или навигацию в макете, следуем инструкциям из гайдов:

    • Редактируем лигал в макетах,
    • Выбираем ценовую группу в макете,
    • Редактируем навигацию в макетах для наружной рекламы.

    Когда все изменения внесены, переходим к следующему пункту.

    {% else %}

    Editing the layout

    If you need to edit legal information, select a price group or navigation in the layout, follow the instructions from the guides below:

    • Edit legal information in the layout,
    • Select a price group in the layout,
    • Edit navigation in outdoor advertising layouts.

    When you are done with all the changes, move on to the next point.

    {% endif %}
  4. {% if lang == 'ru' %}

    Устанавливаем пресет с настройками PDF

    Скачиваем его из папки PDF Profile. Пресет упростит сохранение мелких и средних печатных форматов. Для установки файл с пресетом открываем в Adobe Illustrator через правую кнопку мыши «Открыть с помощью». После этого ничего не произойдет, но пресет будет установлен.

    Если установить не получится, настраиваем его вручную.

    {% else %}

    Install the preset with PDF settings

    Download it from the PDF Profile folder. The preset will make it easier to save small and medium-sized print formats. To install it, open the file with the preset in Adobe Illustrator using the right mouse button "Open with". You won’t notice any visible changes, but the preset will be installed after the click.

    If the preset cannot be installed, set it up manually.

    {% endif %}
  5. {% if lang == 'ru' %}

    Определяем формат макета

    Способы сохранения на печать отличаются для разных носителей. Всего их четыре:

    • Мелкие печатные носители: все форматы от А7 до А2 — листовки, тейбл-тенты, кассовые постеры, объявления.
    • Средние печатные носители: лайтбоксы А1 и А0.
    • Наружная реклама: сити-форматы и пиллары.
    • Билборды. Формально это тоже наружная реклама, но их надо сохранять с другим разрешением.
    {% else %}

    Figure out the layout format

    Depending on the media you choose, the algorithm of saving the layout varies. There are four formats in total:

    • Small print media, which are all formats from A7 to A2: leaflets, table tents, checkout posters, adverts.
    • Medium print media: A1 and A0 light boxes.
    • Outdoor advertising: city formats and pillars.
    • Billboards. Technically, they are also outdoor advertising, but they should be saved with a different resolution.
    {% endif %}

{% if lang == 'ru' %}Сохраняем макет для мелких печатных форматов{% else %}Saving the layout for small print media{% endif %}

{% if lang == 'ru' %}Инструкция подходит для всех носителей формата от А7 до А2. В основном это листовки, тейбл-тенты, кассовые постеры и объявления.{% else %}The instructions are suitable for all media from A7 to A2, which are mostly leaflets, table tents, checkout posters and adverts.{% endif %}

  1. {% if lang == 'ru' %}

    Выделяем все объекты на макете

    Используем курсор или сочетание клавиш Cmnd+A.

    {% else %}

    Select all objects on the layout

    Use the cursor or the keyboard shortcut Cmnd+A.

    {% endif %}
  2. {% if lang == 'ru' %}

    Растрируем выделенные объекты с разрешением 300 ppi

    Для объединения макета в одну картинку (растрирования) открываем меню в верхней части окна программы. Нажимаем Object, а затем выбираем Rasterize в выпадающем окне. После этого появится диалоговое окно с настройками растрирования. Выбираем настройки, как на скриншоте. Теперь макет объединен в одну картинку, и мы не потеряем элементы при печати.

    {% else %}

    Rasterise the selected objects with 300 ppi resolution

    To merge the layout into one image (this is called rasterisation), open the menu at the top of the Adobe Illustrator window. Click “Object” and then select “Rasterize” in the drop-down menu. After that a dialogue window with rasterisation settings will appear. Choose the settings as shown on the screenshot. Now the layout is merged into one image, and we won't lose any elements when printing.

    {% endif %}
  3. {% if lang == 'ru' %}

    Сохраняем копию макета в формат PDF

    Находим пункт File в меню программы. В выпадающем меню выбираем Save As. Меняем названием файла с Edit на Print, чтобы избежать путаницы. В выпадающем меню Format выбираем Adobe PDF (pdf) и нажимаем кнопку Save.

    {% else %}

    Save a copy of the layout in PDF format

    Find the “File” item in Adobe Illustrator menu. Select “Save As” in the drop-down menu. Change the file name from “Edit” to “Print” to avoid confusion. Select “Adobe PDF” (pdf) in the “Format” drop-down menu and then click “Save”.

    {% endif %}
  4. {% if lang == 'ru' %}

    Выбираем настройки для сохранения PDF

    После нажатия кнопки Save (предыдущий пункт), появится диалоговое окно настройки Adobe PDF. В этом окне, в правой части, находим выпадающее меню Adobe PDF Preset и выбираем Fogra_39_Print. После выбора нужной предустановки, нажимаем кнопку Save PDF.

    {% else %}

    Select the settings to save the PDF

    After clicking “Save” (see previous item), the Adobe PDF settings dialogue box will appear. In this window, on the right side, find the “Adobe PDF Preset” drop-down menu and select “Fogra_39_Print”. After selecting the necessary preset, click the “Save PDF” button.

    {% endif %}
  5. {% if lang == 'ru' %}

    Готово

    Макет сохранен и готов к отправке в типографию. В нем уже назначено нужное цветовое пространство, разрешение, припуски на обрезку и другие технические нюансы, важные для печати.

    {% else %}

    Done

    The layout is saved and ready to be sent to the printing house. It already contains the required colour space, resolution, trimming allowances and other technical nuances important for printing.

    {% endif %}

{% if lang == 'ru' %}Инструкция подходит для сити-форматов и пилларов. Билборд мы сохраняем по-другому из-за особенностей макета.   1. {% if lang == 'ru' %}

    Экспортируем макет в формат TIFF

    Открываем меню в верхней части окна программы и находим пункт File. В выпадающем меню выберите Export, а затем Export As.

    В окне Export As меняем имя файла с Edit на Print, чтобы избежать путаницы.

    В выпадающем меню Format выбираем TIFF (tif) и нажимаем кнопку Export. Проверяем, что опция Use Artboards выключена (без галочки), чтобы сохранить макет с припусками на обрезку.

    {% else %}

    Export the layout to TIFF format

    Open the menu at the top of the Adobe Illustrator window and find the “File” item. Select “Export” and then “Export As” in the drop-down menu.

    In the “Export As” window, change the file name from “Edit” to “Print” to avoid confusion.

    In the drop-down menu “Format” select “TIFF” (tif) and click the “Export” button. Make sure that the “Use Artboards” option is off (unchecked) to save the layout with trimming allowances.

    {% endif %}
  2. {% if lang == 'ru' %}

    Назначаем настройки для сохранения TIFF

    Выбираем такие же параметры, как на скриншоте и нажимаем «ок».

    {% else %}

    Select the same settings as in the screenshot and click "ok".

    {% endif %}
