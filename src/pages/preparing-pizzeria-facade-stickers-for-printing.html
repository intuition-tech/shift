{% if lang == 'ru' %}Готовим к печати наклейки на фасад пиццерии{% else %}Preparing pizzeria facade stickers for printing{% endif %}

{% if lang == 'ru' %}Чтобы разместить наклейку на фасаде, нужно определить тип и размеры окон, подготовить макет к печати и передать его в типографию вместе с требованиями к производству.{% else %}To place a sticker on the facade, you need to identify the type and dimensions of the windows, prepare the layout for printing and submit it to the printing house along with the production requirements.{% endif %}

{% if lang == 'ru' %}Определяем тип и размеры окон{% else %}Identify the window type and size{% endif %}

{% if lang == 'ru' %}Учитываем особенности фасадов и ограничения местного законодательства относительно наружной рекламы на окнах.{% else %}We take into account facade features and local legislation restrictions for outdoor window advertising.{% endif %}

  • {% if lang == 'ru' %}Используем наклейки с ценниками, если в городе не запрещено размещение цен на окнах.{% else %}Use price stickers, unless the city hall prohibits placing prices on windows.{% endif %}
  • {% if lang == 'ru' %}Размещаем наклейки только на первом этаже, на уровне глаз, примерно на высоте 150–165 см от земли.{% else %}Place stickers only on the first (ground) floor, at the eye level, approximately 150-165 cm above the ground.{% endif %}
  • {% if lang == 'ru' %}На витринах со сплошным остеклением наклейки размещаем по центру панели остекления, через одну панель.{% else %}For windows of an all-glass facade, place stickers in the center of the glazing panel, on every other one.{% endif %}
  • {% if lang == 'ru' %}На фасадах с отдельными окнами размещаем наклейки в каждом окне, если ширина простенков между окнами больше ширины оконных проемов.{% else %}For facades with separated windows we place stickers on each window, if the width of partitions between windows is greater than the width of window openings.{% endif %}
  • {% if lang == 'ru' %}На окнах, расположенных на одном фасаде, наклейки должны быть одинаковой высоты. Если окна разной высоты, выравниваем по меньшему из них.{% else %}On windows located on the same facade, the stickers must be of the same height. If windows are of different heights, align the stickers to the smallest one.{% endif %}
  • {% if lang == 'ru' %}Не размещаем наклейки поверх вертикальных разделительных элементов (импостов) остекления.{% else %}Do not place stickers on top of the vertical separating elements (imposts) of the glazing.{% endif %}

{% if lang == 'ru' %}Подбираем размер наклейки, отталкиваясь от размеров окон. Окна можно измерить вручную или взять информацию о размерах из проекта пиццерии.{% else %}Select the size of the sticker based on the size of the windows. The windows can be measured manually or you can find the dimensions in the pizzeria project.{% endif %}

  • {% if lang == 'ru' %}Оптимальный размер наклейки: 40% от самого большого измерения окна.{% else %}Optimal sticker size: 40% of the largest window measurement.{% endif %}
  • {% if lang == 'ru' %}Максимальная высота наклейки: 1200 мм.{% else %}Maximum sticker height: 1200 mm.{% endif %}
  • {% if lang == 'ru' %}Минимальна высота наклейки: 400 мм.{% else %}Minimum sticker height: 400 mm.{% endif %}
  • {% if lang == 'ru' %}Расстояние справа и слева от наклейки: не меньше 18% от ширины окна.{% else %}Distance to the right and left of the sticker: at least 18% of the window width.{% endif %}

{% if lang == 'ru' %}Составляем ТЗ для типографии{% else %}Draw up the ToR for the printing house{% endif %}

{% if lang == 'ru' %}Все наклейки изготавливаем одним способом. Скопируйте текст ТЗ и передайте его в типографию. Когда получите готовые наклейки, проверьте, нет ли дефектов на пленке и сравните изображение с исходным макетом.{% else %}The production process for all stickers is the same. Copy the text of the ToR and submit it to the printing house. When you receive the printed stickers, check the film for any possible defects and compare the image with the original layout.{% endif %}

{% if lang == 'ru' %}ТЗ для типографии{% else %}ToR for the print shop{% endif %}

{% if lang == 'ru' %}Полноцветные изображения. Сольвентная печать 1440 dpi на белой матовой пленке Orajet 3640M F010, с матовой ламинацией. Резка по котуру, выборка, прикатка монтажной пленки.{% else %}Full colour images. Solvent printing 1440 dpi on white matte film Orajet 3640M F010, with matte lamination. Cutting on the contour, sampling, rolling mounting film.{% endif %}

{% if lang == 'ru' %}Готовим макет к печати{% else %}Prepare a layout for printing{% endif %}

{% if lang == 'ru' %}Готовим макет к печати в Adobe Illustrator. Файл с макетом содержит основные слои, доступные для редактирования, а также информационные слои с информацией о материалах, из которых нужно выполнить наклейку.{% else %}We prepare a layout for printing in Adobe Illustrator. The layout file contains basic layers that you can edit, as well as information layers with details about the materials you want to use to make the sticker.{% endif %}

{% if lang == 'ru' %}Чтобы подготовить макет, посмотрите видео или прочитайте инструкцию.{% else %}To prepare the layout, watch the video or read the instructions.{% endif %}

{% if lang == 'ru' %}Инструкция повторяет все шаги, описанные в видео, но в текстовом формате.{% else %}The following instructions repeat all the steps described in the video, but in text format.{% endif %}

  1. {% if lang == 'ru' %}Уточните размеры окон. Измерьте вручную или найдите эту информацию в проекте пиццерии.{% else %}Figure out the dimensions of the windows. Measure them manually or find this information in the pizzeria project.{% endif %}

  2. {% if lang == 'ru' %}Создайте артборд в масштабе 1 к 1, равный размеру вашего окна. Добавьте направляющие, чтобы определить область, на которой будет располагаться наклейка.{% else %}Create a 1-to-1 scale artboard equal to the size of your window. Add guides to define the area where the sticker will be placed.{% endif %}

    {% if lang == 'ru' %}Расстояние справа и слева от наклейки должно быть не меньше 18% от ширины окна. Оптимальный размер наклейки — до 40% от самого большого измерения окна. При этом высота наклейки не должна превышать 1200 мм.{% else %}The distance to the right and left of the sticker should be at least 18% of the window width. The optimal size of the sticker is up to 40% of the largest dimension of the window. The height of the sticker should not exceed 1200 mm.{% endif %}

  3. {% if lang == 'ru' %}Масштабируйте изображение. Выделите слои Cutline и Artwork / Photo+Text и Artwork. Скопируйте их и вставьте в макет. Масштабируйте объекты так, чтобы наклейка располагалась в поле, которое вы создали с помощью направляющих. Наклейка не должна выступать за края. Центрируйте наклейку по горизонтали и вертикали.{% else %}Scale the image. Select the “Cutline” and “Artwork / Photo+Text” and “Artwork” layers. Copy and paste them into the layout. Scale the objects so that the sticker fits in the box you created with the guides. The sticker should not protrude the edges. Center the sticker horizontally and vertically.{% endif %}

    {% if lang == 'ru' %}Перед масштабированием наклейки обратите внимание на качество растрового изображения — оно не должно быть меньше 72 точек на дюйм.{% else %}Before scaling the sticker, pay attention to the quality of the bitmap image - it should not be less than 72 dpi.{% endif %}

  4. {% if lang == 'ru' %}Сохраните отдельно слои Cutline и Artwork в формате PDF. При сохранении выбирайте High Quality Print.{% else %}Save “Cutline” and “Artwork” layers separately as PDF files. Select High Quality Print when saving.{% endif %}

    {% if lang == 'ru' %}Чтобы отдельно сохранить слои, по очереди выключите их и два раза экспортируйте. Так на производстве будет меньше шансов ошибиться и случайно отпечатать контур реза вокруг макета. Проговорите этот момент при отправке на печать.{% else %}To save the layers separately, turn them off one by one and export them twice. This way, there will be less chance for the production to make a mistake and accidentally print the cut outline around the layout. Make sure to mention this point when you send it to print.{% endif %}

  5. {% if lang == 'ru' %}Отправьте на печать. У вас должно получится два файла для каждой наклейки: один с изображением из слоя Artwork, другой — с линиями реза из слоя Cutline. Отправьте их в типографию вместе с ТЗ.{% else %}Submit to printing. You should have two files for each sticker: one with the image from the “Artwork” layer and one with the cut lines from the “Cutline” layer. Send them to the printing house along with the ToR.{% endif %}
