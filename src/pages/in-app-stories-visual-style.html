{% if lang == 'ru' %}Общие принципы{% else %}General principles{% endif %}

{% if lang == 'ru' %}Консистентный дизайн. Стили типографики, цвета и базовые элементы соответствуют стилям приложения.{% else %}Consistent design. Typography styles, colors, and basic elements are aligned with application styles.{% endif %}

{% if lang == 'ru' %}Единый визуал. Используем фирменную типографику, цвета, графические элементы.{% else %}Unified visuals. We use branded typography, colors, and graphic elements.{% endif %}

{% if lang == 'ru' %}Понятные сторис. Поддерживаем текст визуалом: тщательно подбираем изображения под тему, размещаем простые иконки и символы.{% else %}Comprehensible stories. Support the text with visuals: carefully selected images should match the theme, icons and symbols – represent simplicity.{% endif %}

{% if lang == 'ru' %}Сторис легко и быстро считываются. Умеренно используем плашки и иллюстрации, избегаем перегруженности в макетах.{% else %}Stories are easily and quickly read. We use plates and illustrations moderately, and avoid overload of visuals in layouts.{% endif %}

{% if lang == 'ru' %}Цвета{% else %}Colors{% endif %}

{% if lang == 'ru' %}Палитра включает основные, дополнительные цвета и градиенты. Градиент состоит из основного цвета и его более светлого оттенка. Посмотреть правила использования цветов и скопировать значения можно в Фигме.{% else %}The palette includes primary colors, secondary colors, and gradients. {% if lang == 'ru' %}Правила использования цветов{% else %}Rules for using colors{% endif %}

{% if lang == 'ru' %}Шрифт и типографика{% else %}Font and typography{% endif %}

{% if lang == 'ru' %}В сторис используется толко два шрифта. Для заголовков — Rooftop, для наборного текста — Inter.{% else %}Only two fonts are used for stories. Rooftop for headlines and Inter for typesetting.{% endif %}

{% if lang == 'ru' %}Скачать шрифты Rooftop и Inter{% else %}Download Rooftop and Inter{% endif %}

{% if lang == 'ru' %}Другие шрифты не используем. В редких случаях можно добавить леттеринг, разработанный для промо-макетов.{% else %}Other fonts are not put to use. In some rare cases, you can add lettering designed for promotional layouts.{% endif %}

{% if lang == 'ru' %}Стили и допустимые размеры шрифтов{% else %}Styles and permitted font sizes{% endif %}

{% if lang == 'ru' %}Размеры макета и сетка{% else %}Layout dimensions and grid{% endif %}

{% if lang == 'ru' %}Размер макета сторис составляет 1350 px на 2085 px.{% else %}Stories layout size is 1350 x 2085 px.{% endif %}

{% if lang == 'ru' %}Фреймы с настроенными направляющими{% else %}Frames with customized guides{% endif %}

{% if lang == 'ru' %}Также в сторис есть 4 зоны.{% else %}There are also 4 zones in the stories layout.{% endif %}

  • {% if lang == 'ru' %}Основная рабочая зона. В ней находится главная информация на макете, текст не должен выходить за ее границы.{% else %}The main working area. It contains the key information on the layout, the text should not go beyond its borders.{% endif %}
  • {% if lang == 'ru' %}Видимая зона. В ней находятся только графические элементы.{% else %}Visible zone. It contains only graphic elements.{% endif %}
  • {% if lang == 'ru' %}Зона, которая обрезается на мобильных устройствах. Ее видно только при просмотре сторис с компьютера.{% else %}The zone that is invisible on mobile devices. It can be seen only when viewing stories on a computer.{% endif %}
  • {% if lang == 'ru' %}Зона кнопки.{% else %}Button zone.{% endif %}

{% if lang == 'ru' %}Кнопки{% else %}Buttons{% endif %}

{% if lang == 'ru' %}Для того, что пользователи могли совершить целевое действие, в сторис есть кнопки. Кнопки делятся на два вида.{% else %}In order for users to take a targeted action, there are buttons in the stories. Buttons are divided into two types.{% endif %}

{% if lang == 'ru' %}Правила использования{% else %}Rules of use{% endif %}

{% if lang == 'ru' %}Шаблоны{% else %}Templates{% endif %}

{% if lang == 'ru' %}Статичные кнопки. Они всегда располагаются в зоне кнопки. Сверху — кнопка без инонки, Снизу — с иконкой.{% else %}Static buttons. They are always located in the button area. A button without an icon is on the top, with an icon - on the bottom.{% endif %}

{% if lang == 'ru' %}Динамичные кнопки. Нужны для заказа продукта, их можно перемещать по макету. В сторис можно использовать несколько кнопок, но не более трех.{% else %}Dynamic buttons. Their function is ordering a product; they can be moved around the layout. In stories you can use several buttons, but no more than three.{% endif %}

{% if lang == 'ru' %}Мы используем в сторис 3D-изображения, которые разрабатываем сами в команде Приложения.{% else %}We use 3D images in stories that we develop ourselves with the help of our application team.{% endif %}

{% if lang == 'ru' %}Банк 3D-изображений и правила их использования {% else %}3D image bank and rules for their use{% endif %}

{% if lang == 'ru' %}Ещё мы используем графические элементы: шейпы и стрелки.{% else %}We also use graphic elements: shapes and arrows.{% endif %}

{% if lang == 'ru' %}Графические элементы{% else %}Graphic elements{% endif %}

{% if lang == 'ru' %}Мы не используем иллюстрации со стоков и не рисуем их самостоятельно.{% else %}We do not take stock illustrations or draw them ourselves.{% endif %}

{% if lang == 'ru' %}Фотостиль{% else %}Photostyle{% endif %}

{% if lang == 'ru' %}Фотографии продуктов из каталога.{% else %}Photos of products from the catalog.{% endif %}

{% if lang == 'ru' %}Обложки сторис расположены на самом верху главной страницы приложения, поэтому они требуют особенного внимания при разработке.
