Токены собираются из живого CSS скриптом — витрина не может разойтись с кодом. Типографика и компоненты показаны живыми образцами с продовыми классами.

Токены

Палитра

Базовый слой: статичные значения цвета, названные по оттенку и весу. Сами по себе в компонентах не используются — только через семантику. Клик по значению копирует var(…).

Семантические роли

Для чего цвет используется — так и называется. Значения — только ссылки на палитру. Токены с префиксом --shift__ — та же семантика, но специфичная для Shift, не входящая в базовую IDS.
