{% if lang == 'ru' %}Основные{% else %}Main{% endif %}

{% if lang == 'ru' %}Rooftop. Используем его в коммуникациях, в печатных материалах и на диджитал носителях. Он не подходит для объемных текстов, где более четырех строк. В таких случаях используем TTHoves.{% else %}Rooftop. We use it in communications, in printed materials and on digital media. It is not suitable for large texts where there are more than 4 lines. In such cases, we use TTHoves.{% endif %}

{% if lang == 'ru' %}Ropa Arabic. Для арабского текста. При создании одного визуала на двух языках, у арабского увеличиваем размер на несколько пунктов, так как высота знаков у шрифтов при одном и том же размере разный.{% else %}Ropa Arabic. Used for translating creative materials into Arabic. When creating a visual in two languages, we increase the size of the Arabic text by a few points, because the height of the characters in the fonts is different at the same size.{% endif %}

{% if lang == 'ru' %}IBM Plex Sans. Используем для всех креативных адаптаций на курдском языке. Высота знаков у шрифтов при одном и том же размере разная, поэтому при создании одного визуала на двух языках у арабского увеличиваем размер на несколько пунктов.{% else %}IBM Plex Sans. Used for all creative adaptations in Kurdish. The height of the characters in the fonts is different at the same size, so when creating a visual in two languages, we increase the size of the Arabic text by a few points.{% endif %}

{% if lang == 'ru' %}TTHoves. Используется для больших текстов: лигал, технические описания продуктов на упаковке.{% else %}TTHoves. Used for large texts: legal information, product descriptions on packaging.{% endif %}

{% if lang == 'ru' %}Правила набора текста{% else %}Text formatting rules{% endif %}

{% if lang == 'ru' %}Мы пишем текст и названия с заглавной буквы.{% else %}We use uppercase letters for text and titles.{% endif %}

{% if lang == 'ru' %}Фразы, требующие наибольшего внимания, пишем заглавными буквами. Например: FREE, WOW, OFF.{% else %}Phrases requiring the most attention are written in uppercase. For example: FREE, WOW, OFF.{% endif %}

{% if lang == 'ru' %}Заголовок. Шрифт Rooftop, начертание extrabold или bold, интерлиньяж 90–100%.{% else %}Heading. Font Rooftop, extrabold or bold, line spacing 90–100%.{% endif %}

{% if lang == 'ru' %}Лайн нового позиционирования: Rooftop, начертание bold, интерлиньяж 110%.{% else %}Line of new positioning: Rooftop bold, line spacing 110%.{% endif %}

{% if lang == 'ru' %}Подзаголовок. Rooftop, начертание extrabold или medium, интерлиньяж 100–120%.{% else %}Subheading. Rooftop, extrabold or medium, line spacing 100–120%.{% endif %}

{% if lang == 'ru' %}Лигал. Шрифты TT Hoves или TT Hoves Сond. Для коротких лигалов в 1–2 строки допустимо использование Rooftop. Иинтерлиньяж 100–120%.{% else %}Legal copy. TT Hoves or TT Hoves Cond. For short legal copy of 1–2 lines, Rooftop is allowed. Line spacing 100–120%.{% endif %}

{% if lang == 'ru' %}Интерлиньяж{% else %}Line spacing{% endif %}

{% if lang == 'ru' %}Интерлиньяж в заголовках, подзаголовках и базовом тексте, начертание и зачёркивание ценников, выделение выгоды, отбивка цифр пробелами.{% else %}Line spacing in headings, subheadings and base text, font and strikethrough of price tags, highlighting the benefit, digit spacing with spaces.{% endif %}

{% if lang == 'ru' %}В заголовках. Значение межстрочного интервала варьируется от 90 до 110%. Он меньше, когда заголовок состоит из двух строк и нет выносных элементов. И больше, когда заголовок состоит из трех строк и есть выносные элементы.{% else %}In headings. The value of the line spacing varies from 90 to 110%. It is smaller when the heading consists of two lines and there are no ascenders and descenders. And larger when the heading consists of three lines and there are ascenders and descenders.{% endif %}

{% if lang == 'ru' %}Он больше, если в заголовке больше трех строк или у букв много выносных элементов.{% else %}It is larger if the heading has more than three lines or the letters have many ascenders and descenders.{% endif %}

{% if lang == 'ru' %}В подзаголовках и базовом тексте. Значение межстрочного интервала варьируется от 100 до 120%.{% else %}In subheadings and body text. Line spacing values range from 100 to 120%.{% endif %}

{% if lang == 'ru' %}Он больше, если в подзаголовке больше трех строк или у букв много выносных элементов.{% else %}It is larger if the subheading has more than three lines or the letters have many ascenders and descenders.{% endif %}

{% if lang == 'ru' %}Ценники{% else %}Price tags{% endif %}

{% if lang == 'ru' %}Начертание ценника согласуется со стилистикой заголовка. При размещении одного-двух ценников цифры и обозначение валюты делаем одного размера по высоте для консистентности.{% else %}The font of the price tag corresponds to the style of the heading. When placing one-two price tags, the figures and currency designation are made of the same height for consistency.{% endif %}

{% if lang == 'ru' %}Между валютой и цифрой используем узкий пробел.{% else %}We use a narrow space between the currency symbol and the figures.{% endif %}

{% if lang == 'ru' %}Для подчёркивания выгоды используюем разноразмерную композицию: цифры на 40–50% больше обозначения валюты. В случаях, когда символ валюты меньше цены, он выравнивается по верхней границе цифр.{% else %}We use a different size composition to highlight the benefit: the figures are 40–50% larger than the currency designation. In cases where the currency symbol is smaller than the price, it is aligned with the top edge of the figures.{% endif %}

{% if lang == 'ru' %}На сложных фонах цена размещается на плашке, при этом цифры и валюта выполняются в одном размере.{% else %}On complex backgrounds, the price is placed on a plate, while the figures and currency are made in the same size.{% endif %}

{% if lang == 'ru' %}Шейпы{% else %}Shapes{% endif %}

{% if lang == 'ru' %}В макетах используем шейпы разных форм, чтобы добавить фактуру, оттенить или добавить глубины. Так же используем как контейнеры для фото.{% else %}We use shapes of different forms to add texture, highlight or add depth. Also, we use them as containers for photos.{% endif %}

{% if lang == 'ru' %}Не используем баблы как плашки под цены.{% else %}We do not use bubbles as plates under prices.{% endif %}

{% if lang == 'ru' %}Кратко{% else %}Summary{% endif %}

{% if lang == 'ru' %}Выбираем логотип по контексту носителя и фона: используем только утвержденные версии знака и дескриптора, не меняем их пропорции, не искажаем и не собираем новые комбинации вручную. Всегда оставляем вокруг логотипа безопасную зону, проверяем минимальный размер, при котором знак остается читаемым в цифровых и печатных форматах.{% else %}We choose the logo by touchpoint and background context: we use only approved versions of the sign and descriptor, do not change proportions, do not distort them, and do not create manual custom combinations. We always keep a safe zone around the logo and check the minimum size at which the mark remains readable in digital and print formats.{% endif %}

{% if lang == 'ru' %}В кобрендинге фиксируем единый порядок размещения и визуальный приоритет знаков, чтобы иерархия партнеров оставалась стабильной на всех носителях.{% else %}In co-branding, we keep a single placement order and visual priority of marks so partner hierarchy remains stable across all touchpoints.{% endif %}

{% if lang == 'ru' %}Для цвета опираемся на базовую и дополнительные палитры с точными значениями и всегда проверяем контраст на светлых и темных фонах.{% else %}For colour, we rely on core and extended palettes with exact values and always verify contrast on both light and dark backgrounds.{% endif %}

{% if lang == 'ru' %}В типографике подбираем шрифт по задаче: Rooftop — для акцентов и заголовков, TT Hoves и TT Hoves Cond — для длинных и технических блоков, Grenette — только как акцидент. В работе с шейпами сохраняем пропорции и логику форм, используем их как контейнеры и не применяем баблы как плашки под цены.{% else %}In typography, we match the font to the task: Rooftop for accents and headings, TT Hoves and TT Hoves Cond for long and technical blocks, and Grenette only as an accent typeface. When working with shapes, we preserve proportions and form logic, use them as containers, and avoid bubbles as price plates.{% endif %}

{% if lang == 'ru' %}Перед публикацией сверяем композицию на носителях в двух языках, чтобы арабская и английская версии были консистентны по смыслу, иерархии и визуальному ритму.{% else %}Before publishing, we review touchpoint compositions in both languages so the Arabic and English versions stay consistent in meaning, hierarchy, and visual rhythm.{% endif %}
