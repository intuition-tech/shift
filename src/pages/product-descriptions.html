{% if lang == 'ru' %}Описания продуктов{% else %}Product Descriptions{% endif %}

{% if lang == 'ru' %}Описание продукта — это такой же элемент брендинга, как и его название. Оно помогает раскрыть суть, объяснить состав продукта и особенности, описать вкус и создать правильные ожидания. Хорошее описание снимает вопросы клиента, предвосхищает опыт и склоняет к заказу.{% else %}A product description is as much a branding element as the product name. It helps to reveal the essence of the dish, explain the composition and special features of the product; describe the flavor and set the right expectations. A good description leaves no questions for the customer to ask, anticipates the experience and inclines them to order.{% endif %}

{% if lang == 'ru' %}Цель этого гайда — сформулировать единый подход к описанию новых продуктов, который поможет подать их клиенту просто, ясно и в фирменном стиле Додо Пиццы.{% else %}The purpose of this guide is to formulate a unified approach to describing new products, which will help to present them to the customer in a simple, clear way and within Dodo Pizza’s corporate identity.{% endif %}

{% if lang == 'ru' %}Типы описаний{% else %}Description types{% endif %}

{% if lang == 'ru' %}Есть три типа описаний:{% else %}There are three types of descriptions:{% endif %}

  • {% if lang == 'ru' %}ингредиентные,{% else %}ingredient-based,{% endif %}
  • {% if lang == 'ru' %}фирменные,{% else %}branded,{% endif %}
  • {% if lang == 'ru' %}фантазийные.{% else %}fantasy.{% endif %}

{% if lang == 'ru' %}Ингредиентные. Строгое перечисление ингредиентов в правильном порядке (в конце гайда). Такие описания подходят для текущей категории пицц и некоторых закусок.{% else %}Ingredient-based. This is just a plain list of the ingredients in the right order (at the end of the guide). Such descriptions are a good fit for the current pizza categories and some appetizers.{% endif %}

{% if lang == 'ru' %}Фирменные. Описания-сторителлинги. Выделяем особенные ингредиенты или детали рецепта, создаем контекст вокруг продукта, рассказываем почему его нужно попробовать.{% else %}Branded. These are storytelling descriptions. With them, we highlight special ingredients or recipe features, create context around the product, and tell the customer why they should try it.{% endif %}

{% if lang == 'ru' %}Говорим про реальные атрибуты, а не абстракции.{% else %}We talk about real attributes, not abstractions.{% endif %}

{% if lang == 'ru' %}Фантазийные. Игра вокруг образов и слов. Такие описания работают, если соответствуют тону бренда и образу продукта. Если креатив ради креатива — лучше отказаться.{% else %}Fantasy descriptions. This is a narrative built around images and words. Such descriptions work if they match the tone of the brand and the image of the product. If they are creative for creativity's sake, it's better to skip.{% endif %}

{% if lang == 'ru' %}Общие принципы{% else %}General principles{% endif %}

{% if lang == 'ru' %}Придерживаемся главных правил:{% else %}Stick to the main rules:{% endif %}

  • {% if lang == 'ru' %}Работаем в паре: название + описание.{% else %}We develop combinations that include both a title and a description.{% endif %}
  • {% if lang == 'ru' %}Пишем в Тональности Додо Пиццы: доступно, открыто, уважительно.{% else %}We write in the Dodo Pizza tone: accessible, open, respectful.{% endif %}
  • {% if lang == 'ru' %}Не перебарщиваем с эмоциями: не используем слова типа «бешеный», «взрывной».{% else %}We don't overdo it with emotions: we don't use words like “looney” or “explosive”.{% endif %}
  • {% if lang == 'ru' %}Помним о цели: описание должно помочь клиенту сделать выбор.{% else %}Remember the purpose: the description should help the customer to make a choice.{% endif %}
  • {% if lang == 'ru' %}Следим за единой стилистикой рекламных описаний продуктов.{% else %}We follow the style of advertising product descriptions.{% endif %}

{% if lang == 'ru' %}Учитываем ограничения.{% else %}Keep the limits in mind.{% endif %}

{% if lang == 'ru' %}Символьный лимит. С учетом редизайна мобильного приложения, описания не должны превышать 125 символов для всех категорий. Важно укладываться в этот формат без потери мысли.{% else %}Character limit. Taking into consideration our mobile app’s new design, descriptions should not exceed 125 characters for all categories. It's important to fit within this format without losing your thought.{% endif %}

{% if lang == 'ru' %}Порядок ингредиентов. Пока мы используем ингредиентный формат для пицц, важно соблюдать очередность в описании:{% else %}Ingredient order. While we're using the ingredient format for pizzas, it's important to keep the order of ingredients in the description:{% endif %}

  1. {% if lang == 'ru' %}Сначала основной ингредиент (например, креветки).{% else %}First the main ingredient (such as shrimp).{% endif %}
  2. {% if lang == 'ru' %}Затем важный компонент рецепта (например, песто).{% else %}Then the important component of the recipe (e.g., pesto).{% endif %}
  3. {% if lang == 'ru' %}Далее овощи: прежде всего те, на которые возможны аллергии или есть вкусовые ограничения (грибы, лук, сладкий перец).{% else %}Then the vegetables: first of all, those to which you may be allergic or have flavor restrictions (mushrooms, onions, sweet peppers).{% endif %}
  4. {% if lang == 'ru' %}Затем овощи второго плана (томаты, маринованные огурцы.){% else %}Minor vegetables (tomatoes, pickles).{% endif %}
  5. {% if lang == 'ru' %}После этого — моцарелла.{% else %}After that, mozzarella.{% endif %}
  6. {% if lang == 'ru' %}В самом конце — соус-основа (фирменный томатный или альфредо).{% else %}At the very end, the base sauce (specialty tomato or alfredo).{% endif %}

{% if lang == 'ru' %}Этот порядок помогает клиенту быстро считывать главное, видеть ключевые вкусы и принимать осознанное решение.{% else %}This order helps the customer quickly read the main thing, see the key flavors and make an informed decision.{% endif %}
