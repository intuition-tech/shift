With the informational ones we speak shortly and clearly, straightforward, in 1-2 slides.{% endif %}

{% if lang == 'ru' %}Принципы сторителлинга{% else %}The principles of storytelling{% endif %}

{% if lang == 'ru' %}Цепляющая обложка. Привлекаем внимание пользователя с помощью информативной и интересной для него обложки. Для вовлекающей или игровой механики используем вопросы и интригу, для анонсов продуктов или информационных сторис — прямой, понятный посыл.{% else %}A catchy cover. Grab the user's attention with a descriptive and fascinating cover. For engaging or game mechanics we use questions and create intrigue, and for product announcements or informational stories we go for a straightforward, clear message.{% endif %}

{% if lang == 'ru' %}При выборе названия учитываем, что в одну строку помещается до 10 знаков. Общее ограничение по знакам: до 30 символов, включая пробелы.{% else %}When choosing a heading, please remember that one line can only contain up to 10 characters. Total limit is up to 30 characters, including spaces.{% endif %}

{% if lang == 'ru' %}Вступление на первом слайде. Пользователь может перейти в сторис двумя способами: через обложку или после просмотра предыдущих сторис. Чтобы поддержать сторителлинг, выносим на первый слайд небольшое вступление, в котором обозначаем главную мысль.{% else %}The introduction is on the first slide. The user has two chances to see the stories: through the cover or after viewing the previous stories. To maintain storytelling, we put down a small introduction on the first slide, where we highlight the main idea.{% endif %}

{% if lang == 'ru' %}Один слайд — одна мысль. Соблюдаем сторителлинг, но не растягиваем одну мысль на несколько слайдов. После каждого слайда пользователь должен запоминать одну главную мысль — выносим её в заголовок, а в абзацах раскрываем подробней.{% else %}One slide - one idea. We stick to the storytelling principle, but we do not spread one single idea over multiple slides. After each slide, the user should keep in memory one key item, so we introduce it on the heading, and then reveal it in more detail in the following paragraphs.{% endif %}

{% if lang == 'ru' %}Ясный текст. Пишем грамотно, понятно и емко: следим за знаками препинания, избегаем канцеляризмов, используем живой язык и простые формулировки. Если информации много, разбиваем ее на несколько слайдов.{% else %}Clear text. Write accurately, clearly and meaningfully: watch out for punctuation, avoid clericalisms, use lively language and simple wording. If you have too much information to share, spread it into several slides.{% endif %}

{% if lang == 'ru' %}Цельное повествование. Следим за единством текста: соблюдаем логику и последовательно развиваем основную идею. Подборки объединяем общей темой, обозначаем ее в начале и/или в конце серии сторис.{% else %}Coherent narrative. Ensure the unity of the text: follow the logic and develop the main idea consistently. Selections are collected within a common theme, so we mark it at the beginning and/or end of a series of stories.{% endif %}

What partnerships we choose, what events we participate in.{% endif %}

{% if lang == 'ru' %}Глоссарий — словарь терминов, который мы используем. Если есть сомнения, сверяемся с ним.{% else %}Glossary — dictionary of terms that we use. If there are doubts, we look it up.{% endif %}

{% if lang == 'ru' %}Главред — сервис, который помогает очистить текст от словесного мусора, проверяет на соответствие информационному стилю.{% else %}Glavred — service that helps to clear the text of verbal garbage, checks for compliance with the information style.{% endif %}
