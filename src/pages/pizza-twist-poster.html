{% if lang == 'ru' %}Постер Pizza Twist{% else %}Pizza Twist poster{% endif %}

{% if lang == 'ru' %}Адаптируем под локальный рынок и готовим к печати интерьерный Постер Pizza Twist. В гайде — видеоинструкция и ее расшифровка с иллюстрациями.{% else %}We adapt to the local market and prepare for printing “Pizza Twist” interior poster. The guide includes a video tutorial and its transcript with illustrations.{% endif %}

{% if lang == 'ru' %}Рассмотрим, как вставить текст на языке страны, выбрать цвет фона и правильно сохранить постер для передачи в типографию.{% else %}Let's figure out how to insert text in the local language, choose a background colour and correctly save the poster for printing.{% endif %}

{% if lang == 'ru' %}Прежде чем приступить к редактированию макета, выполните несколько предварительных шагов:{% else %}Before you start editing your layout, follow a few preliminary steps:{% endif %}

  1. {% if lang == 'ru' %}Установите пресет для сохранения PDF.{% else %}Install a preset to save PDF files.{% endif %}
  2. {% if lang == 'ru' %}Уточните, какой цвет фона и текста нужно использовать в макете. Эта информация есть в проекте пиццерии.{% else %}Specify what background and text colour to use in the layout. This information is available in the pizzeria project.{% endif %}
  3. {% if lang == 'ru' %}Подготовьте или запросите перевод текста на локальный язык, если английский не основной язык в вашей стране.{% else %}If English is not the primary language in your country, prepare a translation of the text into the local language.{% endif %}

{% if lang == 'ru' %}1. Скачайте макет из папки Edit{% else %}1. Download the layout from the Edit folder{% endif %}

{% if lang == 'ru' %}Все интерьерные постеры хранятся в папке Posters - v1.1. Скачайте макет постера Pizza Twist и откройте его в Adobe Illustrator. Чтобы отредактировать его, вам понадобится файл Edit.{% else %}All interior posters are stored in the “Posters - v1.1” folder. Download the “Pizza Twist” poster layout and open it in Adobe Illustrator. You will need the “Edit” file to edit the layout.{% endif %}

{% if lang == 'ru' %}2. Определите язык{% else %}2. Determine the language{% endif %}

{% if lang == 'ru' %}Мы предоставляем постеры с текстом на английском языке. Если в вашей стране английский не основной язык, переведите текст на локальный язык.{% else %}We provide posters with text in English. If English is not the primary language in your country, translate the text into your local language.{% endif %}

{% if lang == 'ru' %}3. Выберите цвет текста и вставьте перевод{% else %}3. Select the colour of the text and insert translation{% endif %}

{% if lang == 'ru' %}В слое с текстом есть два подслоя — Black и White. Выберите вариант нужного цвета, лишний слой удалите. Какой цвет текста использовать, указано в проекте пиццерии.{% else %}There are two sub-layers in the text layer, “Black” and “White”. Select the option of the desired colour, and remove the extra layer. Pizzeria project specifies which text colour to use.{% endif %}

{% if lang == 'ru' %}Вставьте перевод в соответствующие блоки по аналогии с англоязычной версией. Если английская версия постера вам подходит, оставьте текст без изменений и переходите сразу к шагу 6.{% else %}Insert the translation into the corresponding blocks just the way they are in the English version. If the English version of the poster works well for you, leave the text unchanged and go straight to step 6.{% endif %}

{% if lang == 'ru' %}4. Отредактируйте заголовки{% else %}4. Edit the headings{% endif %}

{% if lang == 'ru' %}Текст на макете вписан в прямоугольники. При редактировании текста линии (грани прямоугольника) можно двигать, но особенности взаимного расположения объектов должны сохраняться.{% else %}The text on the layout is inscribed in rectangles. When editing the text, the lines (rectangle edges) can be moved, but the features of the mutual arrangement of objects must be preserved.{% endif %}

{% if lang == 'ru' %}Если после перевода заголовков количество строк увеличилось, отредактируйте вариативность шрифта, сохраняя акценты.{% else %}If the text happens to be longer after the headings have been translated, edit the font variation, keeping the accents where they were put.{% endif %}

{% if lang == 'ru' %}Если заголовки перекрывают основной текст, опустите ниже горизонтальную разделительную линию и текст под ней.{% else %}If headings overlap the main text, lower the horizontal separator line and the text below it.{% endif %}

{% if lang == 'ru' %}5. Отредактируйте основной текст{% else %}5. Edit the main text{% endif %}

{% if lang == 'ru' %}Если основной текст вышел за пределы нижней границы прямоугольника, в который он вписан, вытяните границу до нижней направляющей. Для этого выделите точки, по которым сделано скругление углов, и сдвиньте линию вниз.{% else %}If the main text extends beyond the bottom border of the rectangle in which it is inscribed, extend the border to the bottom guide. To do this, select the points where the corners are rounded and move the line down.{% endif %}

{% if lang == 'ru' %}Выровняйте текст, чтобы он не выглядел рваным по правому краю. Следите за тем, чтобы сохранялся «контраст сдвига».{% else %}Align the text so it doesn't look jagged along the right edge. Make sure that the "shift contrast" is maintained.{% endif %}

{% if lang == 'ru' %}Отредактируйте линии под фразами «World classics» и «Local twist». Линия должна быть равна ширине текстового блока под ней.{% else %}Edit the lines located under the phrases "World classics" and "Local twist". The width of the line should be the same as the one of the text block below.{% endif %}

{% if lang == 'ru' %}Если основной текст стал длиннее и перекрыл фразу «This is Dodo Pizza», удалите ее. Постеры размещаются внутри пиццерии, то есть в зоне бренда, а значит, гость и так понимает контекст.{% else %}If the main text has become longer and overlaps the phrase "This is Dodo Pizza", delete it. The posters are placed inside the pizzeria which is already the brand area, and that means that guests already understand the context.{% endif %}

{% if lang == 'ru' %}6. Выберите цвет фона{% else %}6. Select the background colour{% endif %}

{% if lang == 'ru' %}В слое Background выберите цвет, который указан в проекте пиццерии.{% else %}In the “Background” layer, select the colour that is specified in the pizza shop project.{% endif %}

{% if lang == 'ru' %}7. Объедините слои{% else %}7. Merge layers{% endif %}

{% if lang == 'ru' %}Проверьте, что в слое Text и Backgroung остались только те элементы, которые будут напечатаны. Удалите все скрытые слои.{% else %}Check that only the elements that will be printed are left in the “Text” and “Backgroung” layer. Remove any hidden layers.{% endif %}

{% if lang == 'ru' %}Выделите слой Background и растрируйте его. Для этого выберите в меню в верхней части экрана пункт Object - Rasterize. В диалоговом окне проверьте пункт Resolution: растрируйте макет в высоком разрешении 300 ppi.{% else %}Select the “Background” layer and rasterize it. To do this, choose “Object – Rasterize” from the menu at the top of the screen. In the dialog box, check the “Resolution” item: rasterize the layout at a high resolution of 300 ppi.{% endif %}

{% if lang == 'ru' %}8. Сохраните макет{% else %}8. Save the layout{% endif %}

{% if lang == 'ru' %}Сохраните макет в формате Adobe PDF (pdf) с помощью пресета, измените окончание в названии файла с Edit на Print.{% else %}Save the layout in Adobe PDF (pdf) format using the preset, change the ending in the file name from “Edit” to “Print”.{% endif %}

{% if lang == 'ru' %}На экране появится диалоговое окно. Проверьте настройки pdf-файла:{% else %}A dialog box will appear on the screen. Check the settings of the pdf file:{% endif %}

  • {% if lang == 'ru' %}Стиль Adobe PDF: выбран пресет Fogra_39_print.{% else %}Adobe PDF style: Fogra_39_print preset is selected.{% endif %}
  • {% if lang == 'ru' %}Метки и выпуск за обрез: включена опция «Использовать параметры функции “Обрез документа”» и выставлены значения 50 мм для всех сторон. Это важно, так как постеры натягиваются на подрамник: края загибают, чтобы закрыть торцы.{% else %}Marks and Crop Issue: the “Use Document Crop Options” option is enabled and 50 mm is set for all sides. This is important because posters are pulled on a stretcher: the edges are creased to cover the ends.{% endif %}
  • {% if lang == 'ru' %}Вывод: в поле «Целевое пространство» указан «Документ CMYK - Coated FOGRA39».{% else %}Output: the “Target Space” field specifies “CMYK Document - Coated FOGRA39”.{% endif %}

{% if lang == 'ru' %}9. Готово!{% else %}9. Done!{% endif %}

{% if lang == 'ru' %}Теперь макет готов к передаче в типографию. Отправьте специалистам на производстве файл Print.{% else %}Now the layout is ready to be sent to the printing house. Send the “Print” file to the production specialists.{% endif %}
